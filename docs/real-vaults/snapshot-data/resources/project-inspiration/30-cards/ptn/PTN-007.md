# 约束驱动整机重构 Constraint-driven Co-design

## 一句话本质
从最硬的物理约束（无 GPU / 内存 / 功耗）出发，反向协同设计模型选择、推理实现、内存策略与交互方式。

## 结构
锁定硬约束 → 选最小可用模型 → 自写推理（Zig GGUF + NEON）→ mmap / lazy load → 交互适配输入受限。

## 改变了什么
相对"先做模型再想部署"，约束在前、整机协同，得到能真实运行的端侧体验。

## 哪些只是包装
只量化模型但不解决内存 / 交互整机问题，不算整机重构。

## 适用边界与误用
工程门槛高；通用性与可移植性受限。
