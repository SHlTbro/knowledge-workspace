## 机制
Evidence-before-Narration / Authority Separation。deterministic investigation engine 根据规则生成 evidence / attack stages / initial risk（authority）；UEBA ensemble 只提供行为异常上下文与受限 score refinement（bounded refinement）；graph correlation 找结构相似的历史 incident；local LLM 在冻结后的 incident context 上生成 narrative、建议和问答（interpretation）。LLM 不能改变 evidence 或 risk score，UEBA 也不能独立创建 investigation。

## 相对普通做法改变了什么
普通做法：直接把日志喂给 LLM → 叙事能力越强，越容易把不存在的因果关系写得像真的 → LLM 拥有事实层写权限。
本机制：三层权威分离，生成模型最擅长解释，最不应该决定"发生过什么"。不同信息源不是平权民主。

## 适用场景
安全事件分析、RAG/Agent 审计、合规调查、任何"LLM 可以讲故事但不能改事实"的场景。
