# 依据约束的动作写入 Evidence-grounded Action

## 一句话本质
写动作（建单 / 改数据）前，先用权威来源（官方文档 MCP）丰富并约束内容，再以结构化 schema 写入业务系统。

## 结构
抽取非结构化信息 → 检索权威依据（Docs MCP）→ 补 acceptance criteria → 结构化 action schema → Jira MCP 写入。

## 改变了什么
相对"LLM 直接生成工单"，输出有出处、结构统一、直接进执行系统，减少幻觉与返工。

## 哪些只是包装
RAG 只用于展示参考、但不约束最终写入内容的，不算依据约束。

## 适用边界与误用
受权威源覆盖度限制；写入动作需明确责任归属；schema 有设计成本。
