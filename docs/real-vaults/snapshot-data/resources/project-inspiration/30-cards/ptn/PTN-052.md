## 机制
每个主张必须来自当前会话实际打开的来源，按 systematic review > guideline > trial > cohort > mechanism > anecdote 层级评分。结论强度（holds up / mostly true / it depends / overstated / does not hold up / insufficient evidence）由最高证据层自动约束。无来源时直接拒绝回答。

## 相对普通做法改变了什么
普通做法：RAG 有引用就行 → 模型可以用"看起来合理"的链接支撑强结论。
本机制：引用有等级，verdict 强度不能超过 best source 允许的强度；无来源则"No source, no verdict"。

## 适用场景
高风险 RAG（医疗/法律/金融）、知识库输出质量控制、任何需要"搜索到了≠证明了"的场景。
