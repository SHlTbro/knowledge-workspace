# 评价系统也要被评估 Calibrate the Judge

## 一句话本质
评测 / 裁判模型本身是系统组件，必须用扰动集、多裁判、置信区间来校准其敏感性与特异性。

## 结构
构建 perturbed ground-truth 集 → 多 judge（70B + 32B）→ CoT / 非 CoT 对比 → sensitivity/specificity + Wilson CI → 反谄媚。

## 改变了什么
相对"用一个 LLM 当裁判就信"，承认裁判会被骗 / 会谄媚，量化其可靠性。

## 哪些只是包装
跑了个 LLM 打分但不校准、不报 CI 的不算。

## 适用边界与误用
仍需人类 ground truth；自动指标不能替代领域专家。
