## 机制
Source-weighted Learning。强 teacher distillation 后，伪标签不能等权灌入；给不同噪声来源分配不同"信号预算"。不把 pseudo labels 当 1.0 真值，而是压低 label-sum cap，并与真实 LSS 注入分开到不同 focal samples。多轮 self-training 中第三轮回落说明"自蒸馏越多越好"是错误直觉。

## 相对普通做法改变了什么
普通做法：distillation + 少量真实标签形成强 base → 直接加入 pseudo labels → 反而把模型拉坏。
本机制：伪标签是有预算的弱证据，不是"有标签/没标签"二元变量。信号强度与可信度对齐，弱来源不能淹没高质量 ground truth。

## 适用场景
半监督学习、知识蒸馏、RAG 检索加权、Agent Memory 证据加权、任何"多来源数据不等权"的场景。
