## 机制
每张照片/输入不是独立做 caption，而是与工单要求逐项匹配，记录 matched / missing / conflicting evidence。多轮回复中持续追踪证据缺口，生成精确补拍问题，直到所有 contract 都有对应证据才完成。缺证据时保持 missing，不强行完成。

## 相对普通做法改变了什么
普通做法：每张图独立识图 → 输出 caption → 不追踪跨轮证据缺口。
本机制：维护证据状态机（matched/missing/conflicting），多轮累积，缺证据时继续追问而不是猜测。

## 适用场景
远程运维验收、AI Coding 验收（需求/截图/测试日志/接口响应/diff 分别为 evidence item）、合规审计、任何需要"证据齐全才算完成"的多轮任务。
