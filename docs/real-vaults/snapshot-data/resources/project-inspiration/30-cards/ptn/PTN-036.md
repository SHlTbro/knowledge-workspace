## 复合：结果遥测 + 证据可定位

Expected Outcome → Missing/Abnormal Signal（PTN-029）→ Evidence Locator（PTN-028）→ Human Review（PTN-030）。

系统不仅记录 error，还记录"用户目标是否完成"；一旦发现异常，所有判断都必须定位到可复核证据（前端失败秒点、时间戳、line item、对应规则）。重点不是更多日志，而是让每个失败和结论都能被人快速复核。
