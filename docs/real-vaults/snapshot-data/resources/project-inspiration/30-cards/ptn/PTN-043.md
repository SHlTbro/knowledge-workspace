## 机制
每一句对外文本必须能映射到允许的事实源。生成后验证器检查生成内容是否都能在源材料中找到依据，无源内容自动 BLOCK 或纠正。配合 PII 匿名化和多道人类审批。

## 关键设计
- claim ledger：每个输出 bullet 附 source_span
- 无源内容 → BLOCK（不是降级，是硬阻断）
- PII 匿名化在输入侧
- 两道人类审批在输出侧

## 适用场景
简历生成、招聘匹配、法律文书、医疗报告、任何"编造一个细节就可能造成严重后果"的生成场景。
