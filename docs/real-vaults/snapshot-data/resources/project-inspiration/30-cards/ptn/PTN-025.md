## 政策预演 / 对抗模拟（Policy Pre-deployment Simulation）

把"规则/政策/权限配置"本身当作待测软件，在真实部署前用合成环境和 Agent 群做压力测试。

**与 baseline 的差异：** 传统做法是上线后等事故或依赖专家推演/有限压力测试。这里 Agent 群是自动生成的 adversarial input，政策是被测对象，观察二阶行为（herding、操纵、稳定性）。

**适用场景：** 新 Agent 权限规则、企业流程变更、金融监管政策、平台规则调整。

**关键约束：** 模拟环境必须有保真度校准；不保真的数字孪生会产生虚假信心。
