## 机制
权限不是 Agent 静态 scope，而是 agent binding × principal state × action category × time 的函数。人的法律/生命状态（死亡、失踪、失能、未成年）动态改变整组 Agent 的可行动边界。交易前 Agent 只获得"允许/拒绝及后续动作"，不必得到敏感诊断。

## 关键设计
- Ed25519 签名证书 + TTL + reason_code
- k-of-2 独立死亡证明
- institutional writer 更新 civil state

## 适用场景
Personal Agent 权限管理、企业 Agent 审批流、医疗/金融高风险操作的动态授权。
