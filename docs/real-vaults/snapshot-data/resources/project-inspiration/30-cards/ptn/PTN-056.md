## 机制
MCP 服务注册时先过 security gate（prompt injection/越权/policy violation，触发直接归零），再在 TEE 中运行 golden benchmark（输出正确性 45% + 工具路径 35% + token efficiency 20%），得到硬件签名 attestation。score + transcript hash 上链，raw eval log 存内容寻址存储。其他 Agent 按 capability + threshold 发现服务。新版本发布后旧评分自动过期。

## 相对普通做法改变了什么
普通做法：MCP marketplace 列"支持 swap""支持 research"等自我声明 → 调用者不知道结果是否正确、token 是否浪费。
本机制：registry metadata 包含可验证的 benchmark 成绩 + 硬件 attestation + 永久评价历史。一次评测不终身荣誉。

## 适用场景
MCP/Skill marketplace、Agent 服务发现、内部工具 registry、任何需要"可信性能证明"的场景。
