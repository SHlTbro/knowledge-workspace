# 意图级气闸 Intent-level Airlock

## 一句话本质
在动作"形成但未提交"阶段拦截，把冲突检测从执行后提前到意图层。

## 结构
半形成意图注册（不进 world、planner 看不到）→ 联合冲突探测（JOINT hazard）→ 异议 / 收窄(narrow) → 继续原 turn。

## 改变了什么
传统是 execute→validate→rollback（事后、不可逆）；这里是 pre-commit gate，且用 narrowToSafe 收窄到最宽松安全替代而非拒绝，不打断任务。

## 哪些只是包装
只在最后加一个 LLM"审查员"不是气闸；没有半形成意图隔离与确定性冲突判定的都不算。

## 适用边界与误用
需要可形式化的资源/约束；约束模糊时误报上升；高并发需控制延迟。
