## 复合：Agent = 独立风险主体

Agent Identity + Capability Bundle（PTN-031）+ Per-Agent Credential（PTN-033）+ Budget Cap + Action Passport（PTN-027）+ Audit。

一个真正能操作现实世界的 Agent 应拥有独立身份、独立权限、独立预算和独立审计记录；高风险动作还需要 transaction-time authority proof。适合企业 FDE / Personal Agent 的真实执行层。
