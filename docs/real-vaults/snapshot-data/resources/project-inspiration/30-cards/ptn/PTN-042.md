## 机制
创意流程的质量来自系统性淘汰，而不是模型多采样。生成候选后，主动查询外部现实信号（域名、已有业务、商标、竞品、法规、失败案例）进行反证，解释冲突与 tradeoff，从用户反馈学习方向，反复调整后输出 shortlist。

## 关键步骤
1. Generate：形成策略 + 生成候选
2. Falsify：查询外部信号反证每个候选
3. Narrow：解释冲突 + 从反馈学习 + 收窄到 shortlist

## 适用场景
产品命名、项目创意、PRD 评审、架构选型、技术方案对比、任何需要"多想不如多杀"的决策场景。
