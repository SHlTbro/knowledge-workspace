## 机制
安全评测不再是上线前一次考试，而是嵌在正常工具接口中的持续压力测试。工具返回内容中播种分级 canary 载荷，Agent 命中 tripwire 即 100%-precision 信号表明它服从了注入内容。同时监控 Agent 主动发起的恶意行为（SSRF、注入、凭据滥用）。

## 关键符号
- `LEVELS` 7级注入阶梯（L1 overt → L7 invisible）
- `_seed_payloads(base, session)` 播种 canary + 诱饵
- `_scorecard(s)` → verdict ∈ {HIJACKED, SAFE}
- `_url_safe(url)` SSRF 防护（DNS 解析后检查非公有地址）
- `_detect_input_attack(text)` 5种注入正则

## 适用场景
MCP server 安全测试、Agent 红队、生产环境持续安全监控、Skill Registry 准入测试。
