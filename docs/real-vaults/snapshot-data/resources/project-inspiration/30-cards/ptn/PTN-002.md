# 影子执行 + 证据门 Shadow Execution & Evidence Gate

## 一句话本质
所有高风险变更先在隔离副本真实运行，用客观结果（build/test）作为合并闸门，原仓零触碰。

## 结构
clone shadow → 多 agent 改 → 真实 install/build/test → 通过才由用户 Apply；rollback = 丢弃 shadow。

## 改变了什么
相对"生成即交付 / 让 LLM 自评"，证据来自真实执行而非模型判断；失败天然隔离。

## 哪些只是包装
只在内存里 diff、或让另一个 LLM"review"而不真实 build，不是证据门。

## 适用边界与误用
需要可自动化的验证（build/test）；环境保真度决定可信度；有磁盘/时间成本。
