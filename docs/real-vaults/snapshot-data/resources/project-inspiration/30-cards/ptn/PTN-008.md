# 下沉协议热路径 Hot-path Offload

## 一句话本质
识别高频、可 schema 化的协议路径（MCP tool call），用紧凑二进制 + 零拷贝下沉，握手 / 低频路径仍保留可读格式。

## 结构
setup 交换 schema → 高频路径二进制帧（16B 头 / 对齐 / 类型化）→ O(1) 跳过 → fallback JSON-RPC。

## 改变了什么
把 Agent 系统当分布式系统优化，减少重复编解码；只动热路径、保留兼容。

## 哪些只是包装
全盘替换协议、或无 schema 依据的压缩，不是热路径下沉。

## 适用边界与误用
需双方协同与 schema 稳定；收益依赖调用密度；实现复杂度高。
