# 复合：意图级安全编排 Intent-level Safety Orchestration

## 组合
[[PTN-001]] 意图级气闸 ＋ [[PTN-003]] 事件触发闭环 ＋ [[PTN-005]] 三边界。

## 一句话本质
事件触发的业务闭环中，在意图层设气闸，并按概率/确定/人工三边界分流，构成企业级自主系统的安全骨架。

## 为什么 1+1>2
事件闭环（003）给系统自动触发能力，气闸（001）在动作形成时拦截冲突，三边界（005）确保高后果动作有确定性逻辑和人签字；三者分别管"何时动 / 动得对不对 / 谁负责"，缺一则自主要么危险、要么不被信任。

## 适用场景
高风险、强合规的企业自主流程（财务 / 采购 / 运维）。
