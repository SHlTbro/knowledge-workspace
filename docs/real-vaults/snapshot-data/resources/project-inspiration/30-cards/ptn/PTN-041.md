## 机制
当系统商业目标与用户真实利益可能冲突时，把"拒绝转化"写进策略层，而不是依赖模型自觉。置信度低于阈值时禁止推荐产品/执行转化动作，必要时明确建议"今天别买"，并升级人工。

## 关键设计
- 固定置信度阈值（如 70%）作为硬门
- 低于阈值 → 禁止推荐 + 建议 abstain + 升级人工
- 结合外部条件（天气、季节）动态调整建议

## 适用场景
电商推荐、医疗诊断、法律咨询、招聘匹配、任何有转化激励但可能损害用户利益的场景。
