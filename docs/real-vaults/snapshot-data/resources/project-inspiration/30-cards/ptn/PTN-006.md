# 数据缺失即信号 Missing Coverage as Signal

## 一句话本质
把"应该有数据但没有数据"本身当作一等输出信号（覆盖盲区），而非只分析已收集到的数据。

## 结构
建立"理论应覆盖集合" → 对比实际记录 → 输出缺失 / 盲区（missing population）。

## 改变了什么
相对"汇总现有数据"，主动揭示系统性盲区，改变问题定义。

## 哪些只是包装
普通空值统计 / 缺失值报告不是这个机制（必须有"应覆盖"的参照模型）。

## 适用边界与误用
参照模型的准确性决定结论；需配套隐私与数据治理。
