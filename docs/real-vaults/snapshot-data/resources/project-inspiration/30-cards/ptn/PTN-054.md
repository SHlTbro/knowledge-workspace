## 机制
在 Agent 执行真实支付/高风险动作之前，同步查询 reputation pattern（检测 self-review/集中账户互评）+ RAGAS 质量分（faithfulness/relevancy/precision），合成为 Trust Score，达到用户阈值才执行。approve/block 都写入不可篡改记录。

## 相对普通做法改变了什么
普通做法：Agent 发现另一个 Agent → 直接调用/支付 → 事后看 reputation dashboard。
本机制：委托前同步做 Trust Gate，不达标则 block；不只看平均星级，还检测刷分模式。

## 适用场景
Agent-to-Agent marketplace、Skill/MCP registry 调用前检查、高风险工具授权、任何"先信任再委托"的场景。
