# 复合：事件房间 + 动态团队 + 强制反方 Event Room + Dynamic Team + Mandatory Dissenter

## 一句话本质
业务事件触发临时"房间"，按事件签名动态招 Agent，并行做窄任务，专职反方攻击最佳方案，聚合后经人/确定性 gate。

## 结构
事件 → 动态组队 → 并行窄任务 → dissent 攻击 → 聚合 → gate → 留痕解散。

## 为何 1+1>2
动态组队（PTN-019） alone 可能群体思维；强制反方（PTN-020） alone 在固定团队里浪费；事件闭环（PTN-003）提供从检测到留痕的完整骨架。
