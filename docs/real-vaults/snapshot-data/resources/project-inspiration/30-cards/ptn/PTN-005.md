# 概率 / 确定 / 人工三边界 P/D/H Boundary

## 一句话本质
把任务按性质分到三个边界——概率模型处理模糊部分、确定性逻辑处理规则与计算、人工对高后果决策签字。

## 结构
识别子任务性质 → 概率 / 确定路由 → 高后果节点 human sign-off。

## 改变了什么
相对"全交给 LLM"，把不可让渡的规则与责任留在确定性逻辑和人手里。

## 哪些只是包装
只在最后加个"确认按钮"但中间全是黑盒 LLM，不算三边界。

## 适用边界与误用
需要清晰的领域规则边界；边界划分本身依赖领域知识。
