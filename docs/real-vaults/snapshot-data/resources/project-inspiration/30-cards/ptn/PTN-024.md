# 复合：动作事务合同 Action Transaction Contract

## 一句话本质
任何自动动作执行前都声明：evidence + predicted impact + reversibility + compensating action + human owner；执行中记账，失败按合同补偿。

## 结构
动作前声明合同 → 执行并记账 → 未来状态预测门 → 失败逆序补偿 → 不可逆动作人工接管 → receipt。

## 为何 1+1>2
可逆性分类（PTN-021） alone 缺预测；未来状态门（PTN-015） alone 缺补偿合同；物理世界查询（PTN-017）提供真实影响数据来源。
