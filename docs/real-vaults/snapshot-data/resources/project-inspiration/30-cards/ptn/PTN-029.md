## 负结果遥测（Negative Outcome Telemetry / Silent Failure Detection）

不只监控系统"报出来的错误"，而是定义用户理论上应该成功完成的行为，把"行为失败但无异常"本身当作 incident signal。

**与 baseline 的差异：** 传统 APM 监控 500/崩溃/异常，漏掉"服务都活着但用户用不了"的静默故障（dead click、rage click、checkout abandoned、Agent 说完成但无 tool receipt）。

**适用场景：** 前端用户体验、Agent 任务完成度验证、企业流程闭环检查。

**关键约束：** 需要事件基线和采样策略，否则 rage click 等信号会产生告警洪水；行为失败不一定是 bug（用户犹豫、网络慢）。
