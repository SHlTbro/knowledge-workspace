## 版本化证据对象（Versioned Evidence Object）

把"一次回答"变成可追加、可查询、可验证的证据对象：claim_id + source set + as_of + contradiction + confidence + supersedes。其他系统消费对象和证据，不是一次聊天的自然语言结论。

**与 baseline 的差异：** 传统搜索→回答把某个时刻的证据压成文本，后续来源更新时无法知道原结论依赖了什么、需要改哪部分。这里证据随时间累积，可追溯和撤回。

**适用场景：** 事实核查、知识库重要结论、研究情报、合规证据链。

**关键约束：** 不可篡改只证明"记录没被改"，不证明最初记录是真的；confidence 可能被错误模型系统性抬高。
