# 证据层级与逐条反查 Evidence Hierarchy & Citation Verification

## 一句话本质
按可信度分层处理来源：确定性法定来源 > 不可信开放 Web > LLM 解释层；每条结论必须可反查到原始片段。

## 结构
输入 → 确定性 hard gate（名单/规则）→ 未命中才查开放 Web → hostile-input sanitization → LLM 生成发现 → citation verifier 逐条确认 → 透明评分 + 审计报告。

## 改变了什么
传统 RAG 把所有来源扔进同一个 prompt，LLM 可能被注入或混淆；这里确定性来源先做硬拦截，开放 Web 当不可信输入，结论层独立反查。

## 哪些只是包装
加一个"引用链接"不是反查；citation verifier 必须实际取回原文并核对结论是否被支持。

## 适用边界与误用
实体消歧、来源时效、法律责任是难点；评分公式透明不代表公式正确；适合合规/尽调等高风险场景。
