## 机制
核心指标从"总 token 花费"改为"cost per verified success"。把成本下钻到 agent → task → tool → model → retry → outcome，计算每个任务完成的有效成本和无效重试成本。成本必须与成功率、人工返工和错误损失绑定。

## 关键设计
- cost_receipt：每个 run 记录模型、token、MCP 调用、重试、墙钟时间、最终验收状态
- 下钻维度：agent/task/tool/model/retry/outcome
- 核心指标：cost per verified success（不是 cost per request）
- 成本优化必须与质量指标绑定，防止"更便宜但更多返工"

## 适用场景
企业 AI 成本治理、Agent Runtime 监控、模型路由决策、Coding Agent 效率评估、FinOps for AI。
