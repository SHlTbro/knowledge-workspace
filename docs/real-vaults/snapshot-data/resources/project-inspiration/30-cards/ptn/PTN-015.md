# 未来状态门 Future-State Gate

## 一句话本质
自动变更执行前，要求有"未来若干时间窗不会更糟"的预测证据，而不是只看当前状态是否异常。

## 结构
持续监控当前指标 → 触发优化建议 → Forecast 模块预测未来负载/影响 → 预测可信度达标才允许执行 → 否则保持人工/只读。

## 改变了什么
传统自动扩缩容基于当前阈值（当前低就缩），容易把"暂时空闲"误判为"可以缩"；这里把预测可信度作为执行前置条件。

## 哪些只是包装
加一个"预测"模块但执行不依赖其输出的不算；预测必须有可验证误差记录和置信阈值。

## 适用边界与误用
预测本身可能不准，需记录预测误差并定期校准；适合资源/配置类可逆变更，不适合不可逆动作。
