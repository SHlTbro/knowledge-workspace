## 自适应升级策略（Adaptive Escalation Policy）

根据实时行为历史和风险上下文，动态决定"自动处理 / 轻量审核 / 专家升级 / 人工批准"，而不是一刀切。自动化目标是学习人参与的边际价值最高的场景，不是尽量不让人参与。

**与 baseline 的差异：** 传统统一培训/统一审计强度既浪费又无法在风险发生那一刻介入。这里按风险分层分配审查资源。

**适用场景：** 安全运营、Agent 审计、内容审核、客户服务升级、企业审批流。

**关键约束：** 若只追求降低人工量，会系统性压低高风险升级；行为评分可能形成错误风险标签；自估指标（如 96% 无需人）不能当独立 benchmark。
