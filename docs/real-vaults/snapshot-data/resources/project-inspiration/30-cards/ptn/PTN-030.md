## 决策分解 + 逐行证据绑定（Line-item Decision Decomposition）

把"一个大结论"拆成可逐条挑战的小决策单元，每个单元独立绑定证据（政策条款、病史、药物安全、测试结果），不允许整体结论覆盖局部缺证据。

**与 baseline 的差异：** 传统 RAG/文档问答给一段流畅总结，错误被藏在总结里。这里每个 line item 有独立 recommendation + cited rule，可逐条复核和推翻。

**适用场景：** 保险理赔、医疗审核、PRD 验收、代码审查、合规判定。

**关键约束：** 规则存在地区/版本差异；需要 reviewer 一致性度量和真实数据 benchmark。
