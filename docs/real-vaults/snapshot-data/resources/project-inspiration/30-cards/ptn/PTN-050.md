## 机制
对 AI for Science 是湿实验，对 AI Coding 是真实 build/test，对 FDE 是业务系统状态改变后的可观察结果。模型不能自己给自己打分——必须有一个 LLM 无法伪造的外部 Reality Gate，输出穿过它才算真正进展。

## 相对普通做法改变了什么
普通做法：模型生成候选 → LLM judge 评分 → 排行榜数值好看但和真实可用性脱节。
本机制：生成 → 外部不可伪造验证（湿实验/build/test/业务状态）→ 结果反馈 → 下一轮生成。验证环境是模型无法自我伪造的。

## 适用场景
AI for Science 研发闭环、AI Coding 验收、企业 Agent 价值验证、任何需要"不是 LLM 自说自话"的评估。
