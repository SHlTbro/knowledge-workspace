## 机制
Redact → Attack-test → Policy → Payload-bound Human Approval → Egress。脱敏后不是立刻发送，而是让本地模型主动尝试根据剩余上下文重新猜回占位符；如果猜中，就把该请求提升到高风险。批准绑定 payload hash，避免用户批准 A 内容、Agent 随后偷偷把 B 内容发出去。

## 相对普通做法改变了什么
普通做法：静态 DLP/PII 替换 → 检查"替换了几个字段" → 发送。
本机制：脱敏后主动攻击自己的脱敏结果，本地模型猜不出来不代表外部模型猜不出来；高风险外发绑定具体 payload 让真人批准。

## 适用场景
Personal Agent 数据外发控制、企业邮件/合同/代码脱敏、任何需要"脱敏不等于安全"的场景。
