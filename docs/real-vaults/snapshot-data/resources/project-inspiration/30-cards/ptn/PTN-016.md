# 能力协商与协议切换 Capability Negotiation & Protocol Switch

## 一句话本质
检测到对端能力变化时，系统动态切换到更高效的通信协议，不把人类可读接口当永久底层。

## 结构
默认协议（人类可读）→ 探测对端能力 → 双方确认切换 → 切换到紧凑/机器协议 → 能力不匹配时 fallback。

## 改变了什么
传统 Agent 间通信永远走"文本→语音→文本"的人类链路；这里在确认对端也是机器后，跳过人类编码层直接传数据。

## 哪些只是包装
支持两种协议但没有自动协商和 fallback 的不算；切换必须有双方确认和降级路径。

## 适用边界与误用
切换协议不自动解决安全/认证/可审计性；若数字链路可用，音频传数据通常不是最优；需先 profile 确认瓶颈真在编码层。
