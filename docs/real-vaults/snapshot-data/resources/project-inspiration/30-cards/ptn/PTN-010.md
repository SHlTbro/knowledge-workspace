# 时机 / 顺序可学习 Timing & Order as Reward

## 一句话本质
把"何时行动、以什么顺序、干预多频繁"作为可学习 / 可奖励的对象，而非只优化动作正确性。

## 结构
SFT 打底 → RL 用 order-aware reward（时间位置 + 语义相似 + 顺序）→ 评估 timing/order/intervention cost。

## 改变了什么
相对"只看任务成功率"，显式优化节奏与干预成本。

## 哪些只是包装
固定规则的触发时机不算可学习。

## 适用边界与误用
reward 设计难、易被 reward hack；需专门指标。
