## 能力层构造性拒绝（Capability Denial by Construction）

安全不靠 Prompt 自律，而是从工具能力集合里根本不暴露写权限——模型想写也写不了。deterministic safety limits 在能力层强制只读。

**与 baseline 的差异：** Prompt guardrail 是软政策（模型失误/提示注入即可绕过）；capability surface 是硬边界（工具不存在就无法调用）。

**适用场景：** 高风险 Agent（交易、删除、外部发送）、研究/分析阶段的 Agent、只读审计 Agent。

**关键约束：** 只读模式天然安全但也意味着未证明真正写操作时的安全机制；直接合约调用减少中间层也减少了 UI 确认保护。
