## Agent 即独立风险主体（Agent as Independent Risk Principal）

每个能操作现实世界的 Agent 拥有独立身份、独立权限、独立预算和独立审计记录，可单独冻结和限额。不把多 Agent 做成"多个 prompt 共用一把超级钥匙"。

**与 baseline 的差异：** 传统多 Agent 共享 service account / 超级钱包，一个被注入全部暴露。这里 blast radius 被限制在单个 Agent。

**适用场景：** 企业 FDE、Personal Agent、多 Agent 执行系统、交易 Agent。

**关键约束：** Aivy 源码验证发现实际用共享 KMS 密钥（非 per-agent），说明"独立"的实现程度需要逐组件核实；链上限额只能约束可表达的资金规则。
