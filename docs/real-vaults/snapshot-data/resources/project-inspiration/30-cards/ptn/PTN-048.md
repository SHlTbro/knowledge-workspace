## 机制
创意、项目计划和故障诊断共用一个结构：先生成候选，然后主动寻找反例，再做最小安全实验，最后才执行。
Hypothesis → External/Constraint Falsification → Safe Probe → Updated Belief → Decision

## 组合来源
- Generate → Falsify（SAY MY NAME / PRJ-035）
- Compliance ≠ Feasibility 约束反证（ProjectPlanGuard / PRJ-037）
- SafeProbe 主动诊断（Team a / PRJ-038）

## 适用场景
FDE 企业问题解决：价值不是"模型给答案"，而是快速缩小现实不确定性。项目立项、技术选型、故障排查、PRD 评审。
