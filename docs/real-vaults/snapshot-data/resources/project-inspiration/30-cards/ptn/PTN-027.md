## 交易时授权（Transaction-time Action Passport）

每次高后果动作执行前，Agent 必须携带包含身份、授权范围、本次动作上下文的凭证，由执行方在 transaction-time 验证"权限合法且本次具体行为未越界"。

**与 baseline 的差异：** OAuth/RBAC 只验证"这个客户端有权限"，不验证"这次具体动作是否在授权意图内"。这里把 identity + delegation + scope + intent_digest 绑定到单次动作。

**适用场景：** Agent 发起支付、写操作、外部发送、删除等高后果动作。

**关键约束：** 需要完整协议规范、吊销传播、委托链深度管理；静态声明会退化成漂亮证件。
