## 声明即测试规范（Asserted → Falsified → Validated Profile）

把系统/Agent 的"能力声明"从静态 README 升级为可被主动证伪的测试规范。三阶段：Asserted Profile（从文档/配置生成声明）→ Falsified（自动生成负向测试尝试推翻声明）→ Validated（在测试范围内未被证伪）。

**与 baseline 的差异：** 传统 Agent card / 权限文档是自述，无人验证。这里声明直接编译成测试入口，每次变更后可回归。

**适用场景：** MCP/Skill 能力边界、Agent 权限配置、API 合约、企业内部工具能力声明。

**关键约束：** Validated 只证明"在指定测试范围内未被证伪"，不等于万能安全证明；语义越权（如允许写 docs/** 但写入了个人数据）可能漏掉。
