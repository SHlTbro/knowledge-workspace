# 物理世界并行查询 Fan-out Physical-World Querying

## 一句话本质
把原本无法 API 化的渠道（电话、现场上报、人工触点）临时变成可并行调用的数据源，再结构化汇聚。

## 结构
需求 → 候选渠道列表 → 并行发起物理世界交互（电话/拍照上报）→ 各返回非结构化结果 → 结构化抽取与比较 → 决策/执行。

## 改变了什么
传统把电话/现场当串行人工步骤；这里把它们当作可 fan-out 的异步调用，Agent 负责编排和结构化，人类只处理异常。

## 哪些只是包装
用一个 Agent 逐个打电话不是并行；没有结构化抽取和错误升级策略的只是自动化人工。

## 适用边界与误用
合规（骚扰/同意）、对方意愿、信息理解错误率是硬约束；更适合内部模拟或低风险验证，不适合直接自动外呼生产。
