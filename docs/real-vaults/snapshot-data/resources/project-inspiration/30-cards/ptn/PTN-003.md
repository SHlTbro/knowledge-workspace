# 事件触发业务闭环 Event-triggered Closed Loop

## 一句话本质
以真实业务事件（邮件 / 数据变更）为入口，自动跑通"接收→处理→判定→通知→留痕"，而非等人来聊天。

## 结构
事件监听（Power Automate）→ 提取 / 建记录 → 规则判定 → 通知（Teams）→ 持久化可查。

## 改变了什么
从"人找 AI"到"事件驱动 AI"；闭环且全程留痕，嵌入现有业务流。

## 哪些只是包装
只有聊天界面、要人手动触发、结果不回写业务系统的，不算闭环。

## 适用边界与误用
依赖企业平台与事件源；自动触发需防误触发；规则需可维护。
