# 复合：确定性脊柱 + 生成边缘 Deterministic Spine + Generative Edge

## 一句话本质
把系统拆成"确定性脊柱"（规则、计算、schema、权限、hash、名单）和"生成边缘"（模糊归因、文案、方案探索）；脊柱有否决权，边缘只在脊柱允许的空间内生成。

## 结构
LLM 生成候选 → 确定性规则验证 → 可计算指标 → LLM 解释 → 高风险状态 veto。

## 为何 1+1>2
单独的生成-验证循环（PTN-014）缺证据层级；单独的证据层级（PTN-018）缺闭环重试；加上三边界（PTN-005）后，系统明确知道"什么走确定、什么走概率、什么必须走人"。
