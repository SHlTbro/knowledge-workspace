## 机制
"No fresh indexed data, no green verdict"。每次工具返回值封装 source_id / observed_at / source_version / content_hash / freshness_budget / evidence_class。Action Planner 在有副作用的工具调用前列出依赖的 evidence_id。Gate 做确定性判断：age <= freshness_budget、source_version matches、required evidence class present、no dependency marked stale。不满足时只允许 REFRESH / STEP_UP / UNAVAILABLE。unavailable 是正式风险等级，不是异常兜底。

## 相对普通做法改变了什么
普通做法：工具返回成功 → 直接用 → "查到了"被误写成"安全" → 数据落后几小时也不知道。
本机制：freshness 是一等信息，每个 claim/action 自己声明 freshness_budget；证据太旧时不是"低风险"，而是明确 unavailable 并 fail-closed。

## 适用场景
Agent 钱包签名前检查、RAG 事实新鲜度、招聘状态/价格/法规时效性、任何"数据够不够新"的场景。
