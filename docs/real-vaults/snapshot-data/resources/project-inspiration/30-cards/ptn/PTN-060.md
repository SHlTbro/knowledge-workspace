## 机制
"share functions, not secrets"。每个 MCP function 定义 declarative policy（origin=same-human/any-human/public，assurance=none/selfie/identity，executor=local/0g）。调用者用 SIWE(EIP-4361) 签名绑定 endpoint+function+hashArgs+nonce+expiry。服务端验证后查询 World AgentKit 得到匿名 humanId，再执行 per-function policy。handler 看到 ctx.hors 而非 signature/wallet。高风险函数可 inputRequired 暂停要求 step-up。

## 相对普通做法改变了什么
普通做法：给子 Agent 发一组共享 API keys → 任何 Agent 能调用任何函数 → prompt injection blast radius 巨大。
本机制：函数级 Zero Trust，finance service 暴露 canCommit(amount) 而非完整交易历史；calendar 暴露 findCompatibleWindow() 而非所有事件。授权粒度精确到函数+参数+human origin。

## 适用场景
Personal Agent 网络、MCP service 安全、多 Agent 协作权限管理、任何"共享函数不共享秘密"的场景。
