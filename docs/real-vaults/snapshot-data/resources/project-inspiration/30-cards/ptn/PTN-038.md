## 机制
把可争议的内容判断压成透明 rubric（确定性评分函数），把经济结算放到整数账本与 largest-remainder 分配里，保证收入守恒。允许 Agent 在内容上模糊，但涉及积分、预算、贡献归属时必须进入可审计确定性层。

## 关键符号
- `scoreSignal(data, {recentHeadlines, pendingBeatCounts, agentSignalsIncluded})` → score + breakdown + feedback
- `ACCEPT_THRESHOLD`, `ACCEPT_REWARD` 常量
- `creditAgent(id, amount, type, reason)` 记账

## 适用场景
多 Agent 协作中的贡献积分、知识市场、证据贡献奖励、任务分配与结算。
