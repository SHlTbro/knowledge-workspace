## 机制
Representation Shift。传统 cell tracking 依赖几何/强度/速度手工特征，但"看不到细胞本身"。加入 Soon Net 直接学习细胞的 visual identity / temporal state（interphase / soon-to-divide / just-divided），用三帧局部 3D crop + 小 CNN + transformer 判断细胞状态，同时预测 continuation/division occupancy maps。

## 相对普通做法改变了什么
普通做法：在现有 feature space 继续堆规则/调参数 → 一个多月围攻 segmentation 提升有限。
本机制：问"系统是否根本没有看到决定性信息" → 加入新 representation（视觉状态）→ 结构性提升。先证明新 representation 提供新信号，再考虑更大模型。

## 适用场景
计算机视觉任务、Agent 故障分类（加入调用图/时间序列/截图）、任何"现有特征空间卡住"的场景。
