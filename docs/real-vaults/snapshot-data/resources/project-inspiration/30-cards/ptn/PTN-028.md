## 证据可定位全量分诊（Evidence-addressable Full Triage）

不做抽样审查，而是全量扫描后把每个疑似问题定位到精确证据位置（时间戳、行号、文件、规则条款），人类只复核带证据的高风险片段。

**与 baseline 的差异：** 传统 sample-based review 覆盖率低（如人工回听<30%），且输出是"这个有风险"的模糊标签。这里机器全量扫+证据定位，人类复核效率高且可追溯。

**适用场景：** 合规审计、AI Coding 代码审查、内容审核、日志分析。

**关键约束：** 误报率/漏报率必须度量；参考规则版本必须固定，否则证据指向会漂移。
