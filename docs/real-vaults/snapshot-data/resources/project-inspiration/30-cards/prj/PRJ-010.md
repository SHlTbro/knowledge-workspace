# PKU-FitCoach

## 场景与痛点
视频健身教练不仅要识别动作错误，还要决定何时插话、反馈顺序与频率；节奏本身影响体验与效果。

## 功能流程
progressive SFT → RL 后训练 → order-aware reward 同时考虑时间位置、语义相似度、反馈顺序。

## 技术栈（公开有限）
两阶段方法（SFT + RL），多类评测指标。

## 三段可信度
- 【作者公开】两阶段方法与指标类。
- 【分析推断】任务成功率之外应衡量 Action Timing / Order / Intervention Cost。
- 【未披露】完整超参、算力预算、详细消融、真实用户研究。
