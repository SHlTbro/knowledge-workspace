## 用户与痛点
镜像多肽研发面临靶蛋白制备成本高、数据稀缺等问题。纯生成模型可以轻松产生大量"候选分子"，但如果没有现实实验，排行榜上的漂亮数值和真正可用的 molecular starting point 之间仍隔着整条药物研发链。

## 功能流
生物/化学目标与约束 → 计算设计生成候选 → 根据算法规则筛选 → 选择可实验验证的分子起点 → 湿实验验证 → 将结果反馈为后续研究起点。

## 真正机制
【主办方公开】赛事材料强调项目已经通过湿实验验证算法产生的分子起点，并把它描述为从算法创新到科研验证的完整链路。
【分析推断】真正值得借鉴的是 External Reality Gate：对于 AI for Science、企业 Agent、AI Coding，模型输出只有穿过一个"模型无法自我伪造"的外部验证环境才算进展。对科学是湿实验，对 Coding 是真实 build/test，对 FDE 是业务系统状态改变后的可观察结果。

## 批判
湿实验验证"分子起点"远不等于候选药物有效、安全或可制造；项目如果只验证极少数样本，也可能出现 selection bias。它的研究价值在"把模型输出推入现实反馈"，不是宣称已经解决镜像肽药物研发。

## 迁移方向
把任何 Agent 项目要求改成"必须有一个不可由 LLM 自己打分的 Reality Gate"。招聘 Agent 的最终价值不看 JD 总结质量，而看人工是否接受建议；AI Coding 不看 Reviewer 夸奖，而看独立测试；知识库不看回答文风，而看 evidence-backed claim 的真实准确率。
