## KnowBe4 Agentic Security Coach — 真正的个性化不是"给每个人生成不同文案"，而是动态决定是否需要人介入

**赛事/奖项：** Vista North America Agentic AI Hackathon 2026 2nd Place；KnowBe4。

**功能流：** 汇聚 email/endpoint/browser/identity 等行为事件 → 结合个人历史与风险 → Agent 判断是否自动发即时 coaching、安排补救训练或升级专家 → 超过风险阈值时保留 human approval → 更新个人/组织 Risk Score。

**真正机制：** 【Vista 公开】根据员工实时行为和历史决定自动辅导还是升级专家，并在阈值以上要求人工批准；团队自估 30 天内可显著降低风险，并称 96% 决策无需人处理。【KnowBe4 公开产品】Real-Time Coaching 已把第三方安全信号变成即时 SecurityTip 与 AIDA remediation。【分析推断】Adaptive Escalation Policy：自动化目标不是"尽量不让人参与"，而是学习什么情况下人参与的边际价值最高。

**批判：** 96% 属团队估算，不是独立 benchmark。行为评分可能对员工形成错误风险标签；如果 escalation policy 只追求降低人工量，会系统性压低高风险升级。

**迁移方向：** Agent 审计系统做 adaptive reviewer：低风险重复任务自动通过，中风险进入轻量 reviewer，高风险自动升级深审。
