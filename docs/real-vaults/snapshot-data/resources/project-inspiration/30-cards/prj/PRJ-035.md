## 项目概述
SAY MY NAME 解决产品/公司命名中最浪费时间的部分：不是生成候选，而是来回研究、否决、检查域名与已有企业。普通命名机器人只负责 brainstorm，真正脏活仍交给人。

## 功能流
用户描述品牌与约束 → Agent 形成 naming strategy → 生成候选 → 查询域名 / existing business / preliminary trademark signals → 解释冲突与 tradeoff → 从用户反馈学习方向 → 反复调整 → 输出 Naming Brief

## 真正机制
【主办方公开】Agent 会在命名生成后做域名、已有业务和初步商标信号检查，并根据反馈调整策略。
【分析推断】可迁移机制叫 Generate → Falsify → Narrow：创意流程的质量来自系统性淘汰，而不是模型多采样。这个结构对 PRD、架构选型、项目创意同样有效。

## 技术
主办方没有公开模型、搜索 API、商标数据源或正式消融。无公开 GitHub。

## 批判
preliminary trademark signal 绝不能替代法律检索；域名空闲也不代表可注册商标。若反馈学习没有版本记录，Agent 还可能被偶然偏好带偏。

## 迁移方向
给"项目创意 Agent"加入反证阶段：每个创意必须主动搜竞品、替代方案、法规/开源实现和失败案例，至少找到 3 类杀死条件后才能进入 shortlist。
