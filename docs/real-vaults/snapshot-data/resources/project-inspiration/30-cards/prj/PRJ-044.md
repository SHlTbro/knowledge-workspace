## 项目证据
- 赛事：NanoClaw × Tavily Track 2026 第一名。
- 官方 winners：https://nanoclaw.dev/hackathon/
- 项目 PR：https://github.com/nanocoai/nanoclaw-templates/pull/50

## 用户与痛点
营养信息非常适合制造"引用幻觉"：Agent 很容易根据记忆回答，再补几个看起来合理的链接。这个项目反过来规定：每个主张都必须来自当前会话实际打开的来源，并按营养师编写的证据层级评分。

## 功能流
用户输入 claim/headline/link → Tavily 实时 search + extract → 按 systematic review / guideline body > trial > cohort > mechanism > anecdote 的层级评估 → 输出 holds up / mostly true but / it depends / overstated / does not hold up / insufficient evidence → 每个关键来源生成 quote receipt + 页面截图高亮。

## 真正机制
【作者公开】"Every statement traces to a source she opened in that conversation"，而且"never grades above what the best source allows"；没有 Tavily key 时直接拒绝回答"No source, no verdict"。
【分析推断】这是 Evidence Ceiling：模型的表达自信不能超过证据质量。它跟普通 RAG 的区别在于，不是"有引用就行"，而是引用本身具有等级，并直接限制 verdict。

## 批判
证据等级并不能自动解决研究异质性、发表偏差、终点差异和人群适用性；"一篇系统综述"也不是万能真理。真正生产化还需要时间、地域、人群和指南版本边界。

## 迁移方向
给 Vault / RAG 输出加 Evidence Ceiling：官方契约或实际代码可支撑 VERIFIED；README 或作者宣传只能支撑 AUTHOR_CLAIM；二手博客最多是线索。最终报告的措辞强度由最高证据层自动约束，别再让"搜索到了"偷偷变成"证明了"。
