## 项目证据
- 赛事：ETHGlobal Tokyo 2026，World - Best Use of World ID for Agents。
- 项目页：https://ethglobal.com/showcase/airlock-ph6bx
- 技术：TypeScript/Hono OpenAI-compatible gateway、本地 Qwen 3.5 + vLLM、规则/字典/Presidio/LLM tagging、World Human Continuity OIDC、ENSv2、AES-256-GCM sealed keys。作者披露 35 个 unit tests。

## 用户与痛点
企业或个人 Agent 经常需要把本地邮件、合同、代码、姓名、金额和内部 ID 发给更强的 frontier model。传统方案要么全本地（能力受限），要么把原文直接发出去，再高级一点是做静态 DLP/PII 替换，但"替换了几个字段"并不证明剩余上下文无法反推出真实身份。

## 功能流
请求首先由本地模型处理；确实需要外部强模型时，规则、公司字典、可选 Presidio 与本地模型先把姓名、公司、金额、ID 等替成占位符。随后不是立刻发送，而是让本地模型主动尝试根据剩余上下文重新猜回这些占位符；如果猜中，就把该请求提升到高风险。系统再读取 ENS 中的 egress policy；涉及机密数据时暂停 Agent，通过 World ID for Agents 让真人批准，而且批准绑定 payload hash。最终只有脱敏文本离开本机，返回结果再在本地恢复真实名称，同时把决策写入 hash-chained audit log。

## 真正机制
【作者公开】核心不是普通"PII redaction"，而是 Redact → Attack-test → Policy → Payload-bound Human Approval → Egress。项目还把 World OIDC nonce / IDKit signal 绑定 approval id 与 payloadHash，避免用户批准 A 内容、Agent 随后偷偷把 B 内容发出去。
【分析推断】可称为 Adversarial Egress Gate：安全系统在执行前主动尝试证明自己的脱敏失败，而不是只检查"脱敏器执行成功"。

## 批判
最大风险是"攻击者和守门员共享盲区"：本地模型猜不出来，不代表真正的外部模型、数据经纪商或攻击者猜不出来。脱敏后的语义组合也可能构成准标识符。生产版应增加不同模型/规则族的 adversarial probe，并单独测 false negative。

## 迁移方向
给 Personal Agent / Career Agent 做一个本地 Egress Broker：简历、JD、邮件进入外部模型前输出 redaction receipt；静态 DLP 是 baseline，DLP+LLM tagging 是 B 组，DLP+attack-test 是 C 组。构造 100 条带可推断身份的样本，测 PII direct leak、re-identification success、误拦率和额外延迟。
