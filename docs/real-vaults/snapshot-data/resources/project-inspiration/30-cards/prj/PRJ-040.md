## 项目概述
MarsadOps 对企业内部 AI 工具的成本和使用效率进行实时监控。企业接入多个模型、Coding Agent、RAG 后，财务能看到总账单，工程师能看到 token，但很难回答"这笔 AI 成本到底对应了哪个工作流、产生了什么价值"。

## 功能流
【主办方公开】实时监控企业内部 AI 工具的成本和使用效率。
【分析推断】真正值得做的不是普通成本 dashboard，而是把成本下钻到 agent → task → tool → model → retry → outcome，计算每个任务完成的有效成本和无效重试成本。

## 真正机制
核心指标从"总 token 花费"改为"cost per verified success"。成本必须与成功率、人工返工和错误损失绑定，而不是只看每百万 token 单价。

## 技术与边界
官方没有公开数据采集方式、模型供应商、token accounting、成本归因算法、预算告警或代码仓库。下钻层属于迁移设计。

## 批判
"便宜"可能与任务质量冲突。如果只优化 cost/request，系统会倾向更短上下文、更弱模型或减少验证，反而增加返工。

## 迁移方向
给 Agent Runtime 加 cost_receipt：每个 run 记录模型、token、MCP 调用、重试、墙钟时间和最终验收状态，核心指标改成 cost per verified success。
