# Pixy / Smallest 0.5B Functional LLM

## 场景与痛点
Watch 级 CPU、无 GPU、极低内存环境运行约 0.5B 模型并保持多轮交互。

## 功能流程
Falcon H1 0.5B + 自写 Zig GGUF inference + Arm NEON → mmap / lazy page-in 避免一次装进 RAM → 手表输入受限，设计手写 emoji 输入。

Zig + GGUF + NEON + mmap；PII masking 版本用 SFT；公开多种失败实验。
