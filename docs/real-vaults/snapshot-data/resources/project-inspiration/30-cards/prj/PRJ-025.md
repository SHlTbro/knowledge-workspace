## Eyewitness — 后端指标全绿，不代表用户没有在前端疯狂点一个坏按钮

**赛事/奖项：** Elastic Forge the Future 2026 First Runner-Up；Team Sandboxed。

**功能流：** 收集真实会话行为信号 → 检测 dead/rage click 与放弃结账 → 回放用户看到的页面 → 确认真实失败 → 对齐后端 trace/log → 自动创建工程 case → 附带失败秒点、短视频与后端证据；摘要可翻译成 Hindi/Tamil 给值班团队。

**真正机制：** 【主办方公开】监控行为信号，并将 session replay 与 backend trail 绑定。【分析推断】Negative Outcome Telemetry：不要只监控系统"报出来的错误"，还要定义用户理论上应该成功完成的行为，并把行为失败本身当 incident signal。与传统 APM 的区别是从用户未完成目标反推系统故障。

**批判：** Rage click 不一定是 bug；用户犹豫、网络慢、设计困惑都会产生类似信号。没有事件基线和采样策略，自动建单会制造告警洪水。

**迁移方向：** Agent 系统做 Silent Failure Monitor：任务没有异常，但用户目标未完成，例如 Agent 说"已创建提醒"却没有对应 tool receipt。
