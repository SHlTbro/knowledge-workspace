## 项目概述
FieldDoc 让农民上传病叶照片，结合本地天气、种植季记录和诊断置信度提供建议。核心不是农业识图，而是当系统商业目标（卖药）与用户真实利益可能冲突时，把"拒绝转化"写进策略层。

## 功能流
病叶照片 → 图像诊断与原因区分 → 拉取村级天气 → 结合季节记录 → 置信度判断 → 高置信度给操作建议；低于 70% 禁止推荐产品 → 必要时预约真人农艺师 → 保存季节记录

## 真正机制
【作者公开】低于 70% 时系统"不允许卖任何东西"，必要时甚至明确建议"今天别买"；还会根据村级未来 48 小时天气移动喷药日期。
【分析推断】核心是 Incentive-aware Abstention Gate：当系统商业目标与用户真实利益可能冲突时，把"拒绝转化"写进策略层，而不是依赖模型自觉。

## 技术
主办方披露集成 Google Maps、OpenWeather、Airtable、Gmail、Cal.com；底层视觉模型与训练数据未披露。无公开 GitHub。

## 批判
固定 70% 阈值不代表已校准；作物病害的假阴性可能同样高风险。没有独立 agronomist benchmark，也没有证明语言和地区迁移稳定。

## 迁移方向
在招聘 Agent 中做"推荐 abstention"：当 JD 事实完整度或候选人证据不足时禁止输出"强匹配"，只能升级人工确认。
