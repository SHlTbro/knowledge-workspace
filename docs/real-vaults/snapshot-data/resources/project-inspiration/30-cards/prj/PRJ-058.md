## 项目证据
- 赛事：Biohub - Cell Tracking During Development 2026，Kaggle 1st Place Solution，2026-09-30 发布；赛事由 Biohub 主办，任务是 3D+time 斑马鱼细胞检测、连接、分裂与 lineage reconstruction。
- 赛事页：https://www.kaggle.com/competitions/biohub-cell-tracking-during-development
- 第一名方案：https://www.kaggle.com/competitions/biohub-cell-tracking-during-development/writeups/1st-place-solution

## 用户与痛点
传统 cell tracking 大量依赖几何、强度、速度等手工特征。第一名作者观察到一个很直接却被忽略的问题：这些 tracker"看不到细胞本身"。人类只看相邻三帧就能判断某个细胞是同一个、正在准备分裂还是刚刚分裂，那么模型也应该直接学习这种 visual identity / temporal state。

## 功能流
第一阶段仍是 tracking-by-detection：约 3.1M 参数的 3D U-Net + Cellpose-style head 预测前景概率和指向细胞中心的 flow field，并用 MAE 预训练、少量手工标注 + GT stamp 微调，再用高置信 pseudo label 扩展。第二阶段 Soon Net 对每个细胞裁三帧局部 3D crop，用小 CNN + transformer 判断 interphase / soon-to-divide / just-divided，同时预测 continuation/division occupancy maps。第三阶段 learned linker 使用 detector 几何、Soon Net 输出和 pair features 给 t→t+1 边打分，最后 greedy decode 得到 lineage。

## 真正机制
【作者公开】作者一个多月围攻 segmentation 提升有限，手工标 1800 个细胞虽然对 detector 收益不大，却让他通过长期观察发现"分裂前视觉状态"这一机制；Soon Net 从只做三分类逐步扩展到 occupancy tracking。
【分析推断】这体现了 Representation Shift：当传统 pipeline 在现有 feature space 卡住时，不一定继续堆规则，而是问"系统是否根本没有看到决定性信息"。

## 批判
20 forward passes/frame 推理昂贵；pseudo-label、手工扩充 GT 和竞赛数据分布高度专用；视觉 appearance 在不同显微设备/实验条件下可能漂移。作者主动承认 pseudo-label round 会泄漏到 CV、使 validation 乐观。

## 迁移方向
对 Agent 故障分类也可以做 Representation Audit：如果你现在只用日志文本预测 root cause，加入调用图、时间序列、截图、trace topology 后是否有结构性提升？先证明新 representation 提供新信号，再考虑更大模型。
