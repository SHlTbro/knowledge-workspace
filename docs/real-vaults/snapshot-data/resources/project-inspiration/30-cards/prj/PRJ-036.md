## 项目概述
SmartRecruit 读取 CV、评估岗位匹配并起草邀请，同时包含验证机制阻止生成候选资料中不存在的信息。招聘人员每天阅读大量 CV，普通 LLM 很容易把"合理推测"写成候选人事实。

## 功能流
CV 输入 → PII 匿名化 → JD 要求抽取 → 候选人证据匹配与评分 → 生成邀请草稿 → 验证器检查生成内容是否都能在 CV 中找到依据 → 两道人类审批 → 进入后续招聘动作

## 真正机制
【主办方公开】SmartRecruit 包含验证机制，阻止生成候选资料中不存在的信息；越南公开报道进一步描述两道审批、PII 匿名化以及自动纠正 unsupported information。
【分析推断】最可迁移的不是"AI 筛简历"，而是 Claim-bounded Generation：每一句对外文本必须能映射到允许的事实源。

## 技术
赛事为参赛团队提供 AWS、OpenAI API、基础代码和模拟企业数据；具体模型、评测集与验证算法没有完整公开。无公开 GitHub。

## 批判
自动"纠正幻觉"本身也可能由另一个 LLM 完成，若没有确定性 evidence mapping，仍可能同源失真。匹配评分也涉及公平性与就业歧视风险。

## 迁移方向
给简历定制 Agent 增加 claim ledger：每个输出 bullet 必须附 source_span，无源内容自动 BLOCK。
