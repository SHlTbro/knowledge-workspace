# MediSimplifier

## 场景与痛点
将医院出院摘要简化到易读水平，同时保留医学事实；自动评测本身是否可信也是问题。

## 功能流程
某专业模型 zero-shot 较差 → LoRA 后成为候选中最好之一 → 系统比较不同 Judge + perturbation benchmark 验证评测模型稳定性。

## 技术栈（EXTRACTED）
Python；OpenBioLLM-8B（亦比 BioMistral-DARE / Mistral）；LoRA r=32 alpha=64 rsLoRA，target q/k/v/o，4bit nf4；SFTTrainer，dataset GuyDor007/medisimplifier-dataset；双 Judge（Llama-3.3-70B + Qwen3-32B），708 perturbed JudgeBench，CoT enable_thinking，Wilson CI、sensitivity/specificity。

## 三段可信度
- 【作者公开】ablation、日志、W&B、MLflow、judge calibration、失败假设与混淆因素。
- 【分析推断】最值得迁移的是「评价系统也必须被评估」，而非 LoRA 本身。
- 【未披露】大规模临床专家 ground truth，医学安全不能仅凭自动指标。

## 代码锚点（main, 1bbbfb4bd0）
- `src/train.py` — LoRA 配置与 SFT 训练（含 ablation 口径）
- `calibration_judge_cot.py` — 双 Judge CoT 校准（parse_verdict / wilson_ci / 反谄媚）
- `perturbation_calibration.py` / `src/evaluate.py`
