# VendorGuard

## 场景与痛点
采购收到 PDF 合同后需读条款、对政策、写报告、通知相关人；真正入口是业务事件（邮件附件），而非聊天框。

## 功能流程
Power Automate 检测 PDF（flow 内做文本提取）→ Dataverse 建合同记录 → Orchestrator 分发 Intake / Compliance Scoring / Report&Notification / Q&A → 规则逐条产生红/黄/绿 → Teams 通知 → 历史可查。

## 技术栈（EXTRACTED）
Microsoft Copilot Studio + Power Automate + Dataverse（vg_contract / compliancerule / complianceresult / reviewreport）+ Dataverse MCP；规则外置 rulebook（vg_compliancerule，5 维度 Commercial / Legal / Data Privacy / SLA / Regulatory），不埋 Prompt。

## 三段可信度
- 【作者公开】Dataverse 表、规则、agent instructions、flow、MCP 接法。
- 【分析推断】获奖价值来自业务闭环完整与平台能力利用，而非 Agent 数量。
- 【未披露】真实合同集准确率、法律人员接受率、误判成本、ROI。

## 代码锚点（main, 1582f36dac）
- `docs/agent-instructions.md` — 5 agent 指令（自动触发时全流程不问）
- `docs/flows.md` — 邮件触发流（PDF 提取在 flow，因 Copilot Studio agent 工具不支持文档输入）
- 规则本体 `VendorGuard_Compliance_Rules.xlsx`（rulebook）
