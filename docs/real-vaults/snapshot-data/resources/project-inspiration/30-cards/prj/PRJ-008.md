# ATOM

## 场景与痛点
MCP tools/call 高频路径基于 JSON-RPC，工具名/字段/结构被反复编码解析，随 Agent 与工具调用密度上升成为成本。

## 功能流程
假设双方 setup 时已拥有 JSON Schema → schema-aware binary frames，只替换高频 tool-call 路径 → 握手仍保留 JSON-RPC，支持 fallback。

## 技术栈（EXTRACTED）
C11 参考实现 + Rust 独立实现（atom-rs）；CI、golden corpus、conformance、fuzz、硬件计数器；某些 NEON 优化在不同芯片表现相反，未盲目合并。

## 三段可信度
- 【作者公开】规范、双实现、profile、CI、benchmark。
- 【分析推断】最大价值是把 Agent 系统当分布式系统而非 Prompt 项目。
- 【未披露】真实大规模 Agent 平台部署。

## 代码锚点（main, 9bbf6f67d2）
- `SPEC.md` — 帧/类型/对齐规范
