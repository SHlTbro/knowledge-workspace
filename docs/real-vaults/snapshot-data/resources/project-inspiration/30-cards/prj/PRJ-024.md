## Vigil — 合规审计的价值不是总结电话，而是把违规证据定位到那一秒

**赛事/奖项：** Elastic Forge the Future 2026 Grand Winner；Team Frustrated Engineers；Elastic 2026-09-30 公布。

**功能流：** 多语言销售录音 → 转写 → Elasticsearch 建索引 → hybrid search 对照 SEBI/AMFI 指引 → 发现疑似不合规陈述 → 返回精确音频时间戳 + 对应规则条款 → 合规人员复核。

**真正机制：** 【主办方公开】不是只给"这通电话有风险"的分类标签，而是把违规句子、时间点和法规依据绑定。【分析推断】把 compliance audit 从 sample-based review 改造成 evidence-addressable full-coverage triage：机器先全量扫描，人类只复核带证据的高风险片段。传统人工回听覆盖率不足 30%。

**批判：** 主办方没有公布误报率、漏报率、印度多语种转写错误对合规判定的影响。法规文本会更新，检索版本必须被固定。"全量可扫"不等于"全量可信"。

**迁移方向：** AI Coding 审计不要只输出"这个改动有风险"。建立 Evidence Locator：每条审计结论必须指向 commit、文件、symbol、测试或配置行。
