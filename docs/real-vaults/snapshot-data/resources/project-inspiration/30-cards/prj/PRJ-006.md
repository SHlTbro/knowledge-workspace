# TRACE

## 场景与痛点
极端天气后城市拿不到统一完整数据，尤其是边缘社区；救援覆盖存在盲区。

## 功能流程
接收一线访谈录音（含区域语言）→ 转成结构化、可地理定位的受灾记录 → 识别家庭需求 → 回答「哪些人理论上应被覆盖但完全无记录」。

## 技术栈（公开不足）
Ideate→Hack→Pilot 三阶段，城市与气候专家 mentorship；下一阶段进入真实 pilot。

## 三段可信度
- 【作者公开】三阶段赛制与 pilot 计划。
- 【分析推断】价值来自 missing population 的问题定义，而非模型堆叠。
- 【未披露】模型、ASR、地理编码、召回率、隐私与数据治理细节。
