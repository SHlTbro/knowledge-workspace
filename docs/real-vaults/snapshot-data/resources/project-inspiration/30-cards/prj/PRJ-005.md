# Avalara VAT Agent System

## 场景与痛点
跨国电商 VAT 申报涉及多国规则、数据汇总、校验、对账、填报，责任与合规风险高。

## 功能流程
多个协调 Agent 负责汇总/验证/核对/准备申报 → 真正税务判断用 deterministic tax logic → 提交前保留 human sign-off。

## 技术栈（EXTRACTED，细节有限）
8 Agent + 确定性税务逻辑 + 人工签字；团队为架构/产品/软件工程/Returns Engineering 混编。

## 三段可信度
- 【作者公开】团队构成、确定性逻辑与人工签字边界。
- 【分析推断】跨职能团队帮助快速锁定真实流程节点（无公开复盘证明开发顺序）。
- 【未披露】Agent 具体角色、模型、评测集、失败矩阵；成本数字为团队估算。
