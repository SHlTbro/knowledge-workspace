## 用户与痛点
野外音频标签稀缺、噪声大、站点分布不同。第一名没有简单"用 Perch v2 一把梭"，而是先做 embedding distillation，再低学习率 fine-tune，随后引入多轮 Noisy Student self-training。真正困难的是：distillation + 少量真实 soundscape labels 已经形成很强 base 后，普通 pseudo labels 反而会把模型拉坏。

## 功能流
5 秒音频切片 → Perch v2 等 teacher embedding distillation（cosine loss）→ end-to-end supervised fine-tuning → 对 unlabeled soundscapes 生成 pseudo labels → 不把伪标签当 1.0 真值，而是压低 label-sum cap，并与真实 LSS 注入分开到不同 focal samples → 多轮 self-training → 多架构 / 多 head / genus-level / Amphibia-Insecta specialist ensemble → 针对不同 pipeline 分开 postprocess，再与 Perch native 做 rank blend。

## 真正机制
【作者公开】初期不 distill 的两轮 self-training 约 LB 0.931，distillation 后约 0.935+，直接加入 pseudo labels 会变差；把 PL signal 压低、同时用真实 LSS 抵消噪声后，1/2/3 轮 pseudo 的作者记录约 0.946/0.950/0.949。
【分析推断】本质是 Source-weighted Learning：不同来源的 supervision 不该等权，信号强度应该与可信度和 domain coverage 对齐。伪标签不是"有标签/没标签"二元变量，而是有预算的弱证据。

## 批判
大 ensemble + TTA 成本高；竞赛 validation 和目标站点 priors 很专用；作者指标来自比赛环境。第三轮自训练回落也提醒"自蒸馏越多越好"是错误直觉。作者还明确说额外 Xeno-Canto/iNaturalist 数据对多数目标模型反而变差。

## 迁移方向
对 Vault / Agent Memory 做"证据加权训练/检索"：源码与真实测试权重高，README 次之，LLM 推断最低；同一个结论可以由不同来源累积，但弱来源不能淹没高质量 ground truth。实验测 source-weighted reranking vs equal-weight 的错误晋升率。
