## Agent Passport (Legis Labs) — 支付之前先验证"这个 Agent 此刻有没有资格花这笔钱"

**赛事/奖项：** C:\>DIR 2026 vouch.finance Special Award，奖金 $25,000；团队 Legis Labs。

**功能流：** Agent 发起支付意图 → 提交 agent passport / authority evidence → 银行验证身份与权限 → 对照本次支付的金额、对象、目的 → 允许/升级人工/拒绝 → 留下可审计记录。

**真正机制：** 【主办方公开】Agent Passport 让银行能在 AI-agent payment 执行前检查 Agent。【作者公开】Cvikl 描述为面向金融服务自主 Agent 的 verification protocol。【分析推断】关键不是再造数字身份证，而是把"身份、授权、动作上下文"绑定成 transaction-time authorization。与 OAuth scope 类似，但检查对象从 API 客户端升级到会自主计划的 Agent。

**批判：** 【未披露】没有完整协议规范、吊销传播、委托链深度、跨机构互操作或密钥恢复细节。Passport 若只是静态声明，会退化成漂亮证件。

**迁移方向：** Personal Agent 做 Action Passport：每次高后果动作携带 agent_id、owner、delegation、scope、max_amount/allowed_domain、expiry、intent_digest。
