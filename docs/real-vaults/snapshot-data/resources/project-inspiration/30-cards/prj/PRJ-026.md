## MediAudit-X — 高风险 RAG 不应该只给一个总答案，而要给逐行可核的决策草稿

**赛事/奖项：** Elastic Forge the Future 2026 Second Runner-Up；Team defcon1。

**功能流：** 医院上传材料 → 文档解析为结构化 claim → 检索保险政策、治疗历史、药物安全信息 → 对每个 line item 生成 recommendation + cited rule → 人类 reviewer 复核 → 已批准结果进入 tamper-proof audit log。

**真正机制：** 【主办方公开】医院侧得到结构化 claim，审核者得到带 policy rule、history 和 drug-safety check 的实时建议。【分析推断】Decision Decomposition with Evidence：把"一个大结论"拆成可以逐条挑战的小决策单元，每个单元独立绑定证据。错误不会被一段流畅总结藏住。

**批判：** 医疗与保险规则存在地区差异，药物安全检查不能只靠通用模型。公开材料没有临床 reviewer 一致性、召回率、拒赔误伤或真实患者数据 benchmark。

**迁移方向：** PRD / 代码验收做 line-item decision sheet：每条需求分别标 evidence、实现位置、测试、状态，不允许一个"整体 PASS"覆盖局部缺证据。
