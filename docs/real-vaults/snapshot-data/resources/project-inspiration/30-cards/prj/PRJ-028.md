## Dossier — 事实核查不应该生成一篇"最终答案"，而应该生成一个会继续长大的证据对象

**赛事/奖项：** Hello Future Apex 2026 AI & Agents Track 2nd，奖金 $13,500。

**功能流：** 三个 Agent 持续扫描来源 → 交叉检查 claim → 计算 confidence → 每一步证据写入 HCS attestation → 用户继续贡献新证据 → 同一 story/entity 的 intelligence 随时间累积 → 其他 Agent 可通过 HCS-10 发现并查询该证据对象。

**真正机制：** 【主办方公开】已有大量 attestations 在 HashScan 上，且通过 HOL Registry 可被其他 Agent 发现。【分析推断】关键不是区块链本身，而是把 Answer 变成 Versioned Evidence Object：事实、来源、置信度、验证动作都是可追加的，其他系统消费的是对象和证据，而不是一次聊天的自然语言结论。

**批判：** 不可篡改只证明"记录没被改"，不证明最初记录是真的；confidence 可能被错误模型系统性抬高。HOL 当前公开页上的 trust score 也很低，不能把"上链"当可信代名词。

**迁移方向：** 知识库中把重要结论做成 Evidence Object：claim_id + source set + as_of + contradiction + confidence + supersedes。
