# Procuro

## 场景与痛点
制造/采购团队为补货、比价、确认延迟和追踪发货，需人工逐个给供应商打电话，再把信息抄回 Excel/ERP；团队凌晨 pivot 到这个更具体的业务痛点。

## 功能流程
新采购需求 → Perplexity/供应商库找候选 → 多路 Twilio+ElevenLabs 电话询价/谈判 → 报价和交期结构化比较 → 生成 PO → 后续主动电话追踪 shipment → dashboard 更新。

## 技术栈（EXTRACTED）
Twilio + ElevenLabs + Perplexity；自动化 routine restocking、price negotiation、PO generation、shipment tracking。

## 三段可信度
- 【作者公开】语音代理不是用户面对的聊天入口，而是替企业主动拨号的执行工具；40 小时黑客松产物。
- 【分析推断】关键模式是 fan-out physical-world querying：把原本无法 API 化的电话世界临时变成可并行调用的数据源。
- 【未披露】谈判可靠性、通话合规、对方意愿、报价理解错误责任无系统评测；Demo 到采购生产系统距离大。
