# 企业内部 Operational Sensor Network

## 用户场景
企业内部员工零散上报异常（截图/日志/语音），传统工单逐条处理，无法发现系统性问题。

## 最小功能
- 多渠道入口（截图 OCR、日志粘贴、语音转写）→ 事件抽取。
- 相似问题聚类（embedding + 时间窗）→ 影响面地图。
- 自动建议负责人和优先级。
- 复用 [[PTN-017]]，Python/FastAPI + 向量库。

## 对照组
A：传统工单逐条处理；B：Sensor Network 聚类+影响面。

## 验收指标
重复工单合并率、发现系统性问题的提前量（比单条工单早多久）、误聚类率。

## 最大未知因素
员工上报意愿和质量；跨系统事件的关联键设计。
