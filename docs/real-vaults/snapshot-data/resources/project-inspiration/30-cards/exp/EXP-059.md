## 实验目标
AI Coding 复杂任务不沿单条路径死磕，而是多方案竞争，用真实 build/test 分数决定哪个进入完整实现。

## 复用什么
- hyperreasoning 的 Branch-and-Verify Coding 机制（PTN-063）
- learned controller + tests/compiler feedback 回流

## 新做什么
- 3 个互斥实现策略生成器
- feasibility probe（每个策略最小 patch + 单测，固定预算）
- 真实 build/test 评分决定进入完整实现的策略
- IDE 内搜索过程展示

## 如何验证
对照：A. 单路线 high-thinking；B. Branch Challenger。指标：总 token、首次通过率、architecture rewrite 次数、最终代码质量。最大未知：controller reward 只认短期 tests 可能偏向局部方案。
