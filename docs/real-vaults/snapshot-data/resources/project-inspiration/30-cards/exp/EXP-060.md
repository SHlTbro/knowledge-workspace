## 实验目标
跨会话 AI Coding 不把旧聊天全部塞给新 Agent，只保存项目的未完成状态和决策证据。

## 复用什么
- mesh-code 的 Decision-state Memory 机制（PTN-064）
- 四类持久状态：DECISION / EVIDENCE / PENDING / REJECTED_PATH

## 新做什么
- 四类状态 schema + source hash 绑定
- 新会话状态加载器（只加载当前有效状态）
- 旧 transcript 冷存储
- 状态 lifecycle 管理（过期 decision、撤销、并发写）

## 如何验证
对照：A. 全聊天恢复；B. 结构化状态恢复。指标：token 消耗、错误重复率、stale decision 使用率、新会话首次正确行动率。
