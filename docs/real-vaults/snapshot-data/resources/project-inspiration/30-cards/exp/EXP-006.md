# RAG 覆盖盲区报告器

## 用户场景
RAG / 数据系统回答问题时，主动报告"应该覆盖但库里没有 / 没检索到"的内容，而非只给检索到的答案。

## 最小功能
- 复用：missing coverage as signal。
- 新做：对查询先构造"期望覆盖实体集合"（从问题 / 权威清单），再对比检索结果，输出缺失实体与盲区。

## 对照组
普通 RAG 只答"有什么"。

## 验收指标
人为删除关键文档时系统能报出对应盲区（召回）；误报率可控。

## 最大未知因素
期望集合如何自动构造、误报。
