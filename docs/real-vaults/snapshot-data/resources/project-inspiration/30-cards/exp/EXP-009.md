# 给你的 RAG/Agent 评测器做校准

## 用户场景
你用 LLM 当裁判评估 RAG / Agent 输出，却不知道裁判本身可不可信、会不会被骗。

## 最小功能
- 复用：perturbed 集 + 多裁判 + sensitivity/specificity + Wilson CI + 反谄媚。
- 新做：构造含已知正确 / 被扰动错误的小评测集；跑 2 个裁判；计算 sensitivity/specificity 与 CI；对比 CoT 开关；加反谄媚提示。

## 对照组
单一裁判、不校准。

## 验收指标
得出每个裁判的 sensitivity/specificity 与 CI；识别出裁判在哪类错误上失灵。

## 最大未知因素
构造高质量 ground truth 的成本。
