## 实验目标
防止用户通过创建多个子 Agent 绕过配额限制。删掉 Agent3 再创建 Agent7 不能绕过限额。

## 复用什么
- Proof-of-Human 的 Principal-normalized Quota 机制（PTN-055）
- Web 和 Agent 共用同一 anti-Sybil rule
- UNIQUE(drop_id, human_key) 约束思路

## 新做什么
- 在 Personal Agent 系统中定义 user principal → 子 Agent 的映射
- quota/budget/投递次数/免费资源额度绑定 user principal，不绑定 agent_id
- 子 Agent 创建/删除不重置配额

## 如何验证
测试：A. 创建 Agent1 用完配额 → 删除 Agent1 → 创建 Agent2，配额是否重置（应该不重置）。指标：配额绕过成功率、用户体验影响、合法多 Agent 场景的配额分配灵活性。
