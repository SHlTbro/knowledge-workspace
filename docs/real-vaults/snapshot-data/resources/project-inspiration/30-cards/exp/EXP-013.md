# Contract Validator MCP（生成-裁决循环）

## 用户场景
RAG/FDE 项目中 Agent 生成 SQL、API 调用或业务动作后，需要领域规则校验 schema、权限、金额边界、必填字段，再允许执行。

## 最小功能
- 建一个 MCP Server 暴露 validate_contract(contract_type, payload) 工具。
- Agent 生成候选 → 调 MCP 校验 → 失败带结构化错误回灌 Agent 修正 → 最多 3 次。
- 复用 [[PTN-014]] 循环结构，Python/FastAPI + MCP。

## 对照组
A：传统 JSON Schema + 手写规则（无 LLM）；B：LLM+MCP 生成-裁决循环。测 LLM+MCP 是否减少人工规则数量且不提高漏错率。

## 验收指标
100 条含边界错误的 payload：漏错率、人工规则数量、平均修正轮次、循环终止率。

## 最大未知因素
领域规则能否充分形式化；MCP 校验延迟对 Agent 总延迟的影响。
