## Agent 审计 Adaptive Reviewer — 按风险分层分配审查资源

**复用：** 现有审计 Agent、风险评分。
**新做：** 低风险重复任务自动通过，中风险轻量 reviewer，高风险自动升级深审；阈值以上保留人工批准。
**验证：** 对比固定统一审计 vs adaptive reviewer 的 token 成本、逃逸缺陷和人工审查负担。
