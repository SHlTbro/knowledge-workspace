# 内存受限下的最小模型部署

## 用户场景
在内存受限环境（低配机器 / 容器 / 端侧）跑一个小模型服务。

## 最小功能
- 复用：约束在前、mmap / lazy、整机协同。
- 新做：选小模型 + 量化 + mmap / 按需加载并限制 RSS；FastAPI 起服务，实测内存 / 延迟 / 质量三角；记录失败方案。

## 对照组
默认一次性加载方式。

## 验收指标
在目标内存上限内稳定运行；产出内存-延迟-质量实测曲线。

## 最大未知因素
质量是否降到不可用。
