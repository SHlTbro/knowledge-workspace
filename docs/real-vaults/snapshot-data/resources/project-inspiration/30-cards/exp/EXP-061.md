## 实验目标
RAG/Agent 审计中 LLM 不能直接把"可能"改成 VERIFIED，只能引用 evidence_id 解释或提出 hypothesis。

## 复用什么
- threatFlix 的 Evidence-before-Narration / Authority Separation 机制（PTN-065）
- deterministic layer authority + ML bounded refinement + LLM interpretation

## 新做什么
- Evidence Ledger（parser/test/tool output 写入，带 evidence_id 和 source hash）
- LLM 输出约束（只能引用 evidence_id，不能直接写 VERIFIED）
- hypothesis → evidence 验证流程
- unsupported causal claim 检测

## 如何验证
对照：A. 普通 LLM incident summary；B. Evidence Ledger。注入 100 条无关但语义诱导很强的日志，测 unsupported causal claim rate、事实准确率、LLM 幻觉率。
