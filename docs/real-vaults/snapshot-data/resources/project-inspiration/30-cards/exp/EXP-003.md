# 事件触发的 FastAPI 审查闭环（FDE）

## 用户场景
企业 FDE：某类文档 / 请求经邮件或 webhook 到达，需自动审查、通知、留痕，入口是事件而非聊天框。

## 最小功能
- 复用：事件触发 + 规则外置 + 多步编排 + 通知 + 持久化（不绑定 Power Platform）。
- 新做：FastAPI 接 webhook / IMAP → 存记录（SQLite/PG）→ 用外置规则表（YAML/DB，不埋 prompt）评分 → 生成报告 → 发通知（webhook/IM）→ 全程可查。

## 对照组
纯人工处理 vs 自动闭环。

## 验收指标
端到端跑通；每条结论可追溯到具体规则；处理时延与人工介入点明确。

## 最大未知因素
真实事件量与规则长期维护成本。
