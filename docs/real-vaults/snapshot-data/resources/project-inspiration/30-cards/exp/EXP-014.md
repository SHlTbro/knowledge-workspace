# 本地 Agent Workflow future-state gate

## 用户场景
本地 Agent 自动清理缓存/关闭 worker/缩容前，需要估计未来 30 分钟队列增长与重建成本，避免"省电变事故"。

## 最小功能
- 维护最近 N 小时队列到达率时间序列。
- 执行变更前，预测未来 30 分钟队列长度与重建成本。
- 预测置信度低于阈值则拒绝自动执行，转人工。
- 复用 [[PTN-015]]，Python 实现。

## 对照组
A：静态阈值法（当前队列低就清理）；B：future-state gate。

## 验收指标
错误动作率（清理后队列暴涨需重建）、资源节省、回滚次数、预测误差记录。

## 最大未知因素
到达率的非平稳性（突发流量）；30 分钟窗口是否足够。
