# MCP 高频调用的编码下沉原型

## 用户场景
Python Agent 通过 MCP 高频调用工具，JSON 编解码随调用密度成为开销。

## 最小功能
- 复用：schema-aware、只动热路径、fallback、先 profile。
- 新做：对固定 schema 的 tool call 做紧凑编码（msgpack / flatbuffers / 自定义）+ 缓存 schema；先实测 JSON 开销占比再决定是否做；保留 JSON fallback 与一致性 golden tests。

## 对照组
标准 JSON-RPC。

## 验收指标
回放负载下端到端延迟与 CPU 下降并给出实测 %；紧凑编码与 JSON 100% 语义一致。

## 最大未知因素
真实开销占比是否值得、双方兼容成本。
