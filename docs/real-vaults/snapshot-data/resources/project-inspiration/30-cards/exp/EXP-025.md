## Personal Agent Action Passport — 高后果动作的交易时授权

**复用：** Agent 执行框架、现有认证。
**新做：** 每次高后果动作携带 agent_id/owner/delegation/scope/max_amount/allowed_domain/expiry/intent_digest；执行方在 transaction-time 验证。
**验证：** 构造"权限合法但本次具体行为越界"的请求，测拦截率。
