## 实验目标
把任何 Agent 项目的验收标准从"LLM judge 评分"改成"必须穿过一个不可自伪造的外部验证环境"。

## 复用什么
- MirrorPeptidizer 的 computation→experiment 闭环思路
- External Reality Gate 机制（PTN-050）

## 新做什么
- 为目标 Agent 定义一个 LLM 无法伪造的验证环境（AI Coding 用真实 build/test，招聘 Agent 用人工接受率，知识库用 evidence-backed claim 准确率）
- 在 pipeline 中插入 Reality Gate 节点，输出不穿过则不算完成
- 记录 gate 结果作为训练反馈

## 如何验证
对比：A. 原 LLM judge 验收；B. Reality Gate 验收。指标：gate 通过的输出在真实环境中的实际成功率、用户接受率、回退率。最大未知：Reality Gate 的设计是否真正不可被 LLM 伪造。
