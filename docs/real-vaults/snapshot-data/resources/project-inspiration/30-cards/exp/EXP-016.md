# MCP/A2A 自适应结果协议

## 用户场景
MCP/A2A 通信中，人与 Agent 看 Markdown，Agent↔Agent 在双方 schema/version 匹配后可切紧凑结构；capability mismatch 时 fallback JSON。

## 最小功能
- 定义 capability handshake：双方声明支持的协议版本。
- 匹配则用紧凑二进制/结构化编码；不匹配 fallback JSON。
- 先 profile 真实 payload 与解析成本，有瓶颈才优化。
- 复用 [[PTN-016]]，Python 实现。

## 对照组
A：永远 JSON；B：自适应协议切换。

## 验收指标
大 payload 下的序列化/反序列化延迟、带宽、fallback 触发率、兼容性测试通过率。

## 最大未知因素
是否真有瓶颈（过早优化）；多版本兼容的维护成本。
