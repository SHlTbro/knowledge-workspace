## 实验目标
本地 Egress Broker 放在 Agent 与外部模型之间，脱敏后主动攻击自己的脱敏结果，高风险外发绑定 payload 让真人批准。

## 复用什么
- Airlock 的 Redact → Attack-test → Policy → Payload-bound Approval → Egress 机制（PTN-059）
- 本地模型 + 规则/字典/Presidio 脱敏思路

## 新做什么
- redaction receipt 格式（替换了哪些字段、attack-test 结果、policy 判定）
- 三组对照：A. 静态 DLP；B. DLP+LLM tagging；C. DLP+attack-test
- 100 条带可推断身份的样本测试集

## 如何验证
指标：PII direct leak rate、re-identification success rate、误拦率、额外延迟。最大未知：本地模型猜不出来不代表外部模型猜不出来，需要多模型族 adversarial probe。
