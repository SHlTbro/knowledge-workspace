## 实验目标
给 AI Coding / 知识库多 Agent 做"证据贡献积分"：Agent 每提交一条可复验事实进入 ledger，只有后续被任务真实消费并验证后才获得积分。

## 最小实现
1. ledger 表：fact_id, contributor_agent, content_hash, status ∈ {submitted, consumed, verified, rejected}, reward
2. 提交 API：Agent 提交 fact → 存 submitted
3. 消费验证：任务真实使用 fact 并通过验证 → 标 verified + 发积分
4. 对照：按提交条数计分 vs 按验证后计分

## 验收指标
低质量信息率、重复证据率、可复用率、Agent 行为变化（是否更倾向提交可验证事实）。

## 最大未知
积分激励是否真的提升信息质量，还是只是改变了 Agent 的提交策略。
