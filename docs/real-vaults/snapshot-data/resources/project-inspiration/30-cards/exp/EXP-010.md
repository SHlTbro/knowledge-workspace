# 把干预时机纳入 Agent 评估

## 用户场景
辅助型 Agent（监控 / 教练 / 审核）需要决定何时插话；做对但太啰嗦同样是失败。

## 最小功能
- 复用：timing / order / intervention cost 作为指标。
- 新做：在带"理想干预时刻"标注的小数据集上，除正确率外增加时机误差、干预次数、顺序一致性指标；先用启发式建立基线。

## 对照组
只看最终正确率。

## 验收指标
能量化不同策略的时机误差与干预成本；能区分"做对但过度干预"。

## 最大未知因素
理想时机标注的主观性。
