## MCP Read-only/Mutation 双 Bundle — 能力层构造性拒绝

**复用：** 现有 MCP 工具注册机制。
**新做：** 工具拆为 read-only 与 mutation 两套 capability bundle；研究 Agent 永远加载只读 bundle；受控执行阶段才短时注入写工具。
**验证：** 提示注入场景中，软提示 vs capability removal 的越权成功率对比。
