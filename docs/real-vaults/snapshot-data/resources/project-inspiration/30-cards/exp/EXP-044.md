## 实验目标
为 FDE 企业问题构建统一决策流水线：先生成候选方案，然后反证，再做最小安全实验验证，最后才执行。

## 最小实现
1. Generate：问题输入 → Agent 生成 3-5 个候选方案
2. Falsify：对每个方案搜索反例（竞品、约束、法规、失败案例）
3. SafeProbe：对存活方案设计最小安全实验（read-only probe / dry-run），验证关键假设
4. Decision：基于反证结果 + 实验证据，输出推荐方案 + 证据链 + 未验证风险
5. Execute：只执行通过前三个阶段的方案

## 验收指标
决策质量（用户评分）、从问题到执行的时间、执行后失败率、证据完整度、与"直接给答案"的对照差异。

## 最大未知
流水线的每一步都有成本（token + 时间），是否值得为所有问题都走完整流水线，还是应该根据问题复杂度动态调整。
