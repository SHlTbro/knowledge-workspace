## 实验目标
每轮 AI Coding 执行保留 task、tool path、失败类别、retry、review、最终验收；确定性过滤重复无效轨迹，再从"失败但有学习价值"的 run 生成训练/Skill 候选。

## 复用什么
- DataFlow-Agent 的 TrajectoryFilter 确定性规则思路（parse error/tool error/重复循环/空回答）
- TrajectoryQualityEvaluator 四轴评分思路（goal/efficiency/coherence/tool_use）

## 新做什么
- 适配 AI Coding 场景的 trajectory schema（task/tool path/failure category/retry/review/acceptance）
- "失败但有学习价值"的轨迹分类器（不是简单丢弃失败，而是区分"可学习失败"和"无意义失败"）
- 从轨迹生成 Skill 候选的 pipeline

## 如何验证
验收不是"存了多少日志"，而是后续任务的重复失败率是否下降。对比：A. 全量轨迹训练；B. 仅成功轨迹训练；C. Experience Distiller 过滤+修复后训练。指标：同类任务首次成功率、平均 retry 次数、重复失败模式出现率。
