## 实验目标
给 Agent Runtime 加 cost_receipt：每个 run 记录模型、token、MCP 调用、重试、墙钟时间和最终验收状态，核心指标改成 cost per verified success。

## 最小实现
1. cost_receipt 中间件：包装 Agent run，记录
   - 模型调用：model, input_tokens, output_tokens, cost
   - MCP 调用：tool, params_size, response_size, latency
   - 重试次数、墙钟时间
   - 最终验收状态（verified success / failed / aborted）
2. 下钻查询：按 agent/task/tool/model/retry/outcome 聚合
3. 核心指标：cost per verified success = 总成本 / verified success 数
4. 对照：只看总 token 花费 vs cost per verified success
5. 路由实验：基于 cost per verified success 选择模型/工作流

## 验收指标
成本归因准确率、不同模型/工作流的 cost per verified success 差异、基于该指标的路由决策是否降低总成本、与质量指标的相关性。

## 最大未知
"verified success"的定义和自动检测难度，以及成本归因在多 Agent 协作场景中的复杂度。
