## 实验目标
给 Personal Agent 做 principal-bound tool authority：同一个用户的 Researcher、Writer、Executor 不只各有 scope，还受"当前场景状态"约束。

## 最小实现
1. principal_state 表：user_id, scenario ∈ {job_hunting, payment, daily, travel}, constraints
2. tool authority 函数：authorize(agent_id, tool, params) → check agent.scope ∩ principal_state[scenario].allowed
3. 场景切换：用户手动或自动检测场景变化 → 更新 principal_state
4. 示例：求职投递期允许创建草稿但禁止发送；支付场景超过金额即冻结执行权

## 验收指标
越权操作数（目标 0）、用户手动覆盖次数、场景切换响应时间、Agent 任务完成率变化。

## 最大未知
场景自动检测的准确率，以及用户是否愿意维护场景状态。
