## Policy Pressure Test — 新 Agent 权限规则上线前的对抗模拟

**复用：** 现有 local MCP 工具集合、Agent 执行框架。
**新做：** 合成 100–1000 个用户/异常输入/并发工具调用生成器，对新权限规则做 pre-deployment pressure test。
**验证：** 对比手写测试集 vs 自动生成压力场景，后者发现的额外权限冲突数和失败模式数。
