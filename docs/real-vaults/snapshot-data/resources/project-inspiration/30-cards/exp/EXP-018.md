# 分层证据 Gate 公司研究

## 用户场景
Career/FDE Agent 做公司研究时，先用确定性事实 Gate（官网职位状态、毕业年份、学历），再进入开放 Web 推断。

## 最小功能
- 确定性来源层：官网/官方文档 API 或结构化抓取。
- 开放 Web 层：搜索结果做 hostile-input sanitization。
- citation verifier：每条结论取回原文核对。
- 复用 [[PTN-018]]，Python + 搜索 API。

## 对照组
A：直接 RAG（所有来源混进 prompt）；B：分层证据 Gate。

## 验收指标
100 条"官方事实与媒体说法冲突"集：误判率、结论可反查率、幻觉率。

## 最大未知因素
确定性来源的覆盖率（不是所有事实都有官方源）；citation verifier 的实现成本。
