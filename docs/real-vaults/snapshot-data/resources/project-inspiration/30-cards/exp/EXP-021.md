# MCP 写操作 reversibility_contract

## 用户场景
local MCP/Personal Agent 的写操作（create_file/send_email/create_draft/submit_application）需要预先声明可逆性，执行前展示 transaction plan。

## 最小功能
- 每个 MCP tool 注册 reversibility_contract（CLEAN/RESTORATIVE/TOMBSTONED/MITIGABLE/TERMINAL）、snapshot_required、compensator。
- Agent 执行前生成 transaction plan（不直接调用）。
- TERMINAL 动作默认必须 human gate。
- 复用 [[PTN-021]]，Python + MCP。

## 对照组
A：普通 sequential tool calls + try/except；B：typed reversibility ledger。

## 验收指标
50 条复合工作流故障注入：补偿成功率、不可逆动作误执行率=0、人工接管点合理性。

## 最大未知因素
第三方 SaaS 的现实语义（邮件不可收回）；compensator 的编写成本。
