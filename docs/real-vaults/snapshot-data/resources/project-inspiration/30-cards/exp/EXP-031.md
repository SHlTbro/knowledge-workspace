## 企业 Agent Per-agent Credential Isolation — 独立风险主体

**复用：** 现有多 Agent 框架。
**新做：** Researcher/Writer/Executor 各自 token/scope/quota；Executor 有每日写次数和金额预算；可单独冻结。
**验证：** 对比共享 service account vs 独立 principal 的 blast radius（模拟一个 Agent 被注入后的影响范围）。
