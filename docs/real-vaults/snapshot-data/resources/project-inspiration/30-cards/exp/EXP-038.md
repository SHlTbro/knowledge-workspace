## 实验目标
给"项目创意 Agent"加入反证阶段：每个创意必须主动搜竞品、替代方案、法规/开源实现和失败案例，至少找到 3 类杀死条件后才能进入 shortlist。

## 最小实现
1. 创意生成 → 候选列表
2. 反证 Agent：对每个候选搜索 4 类信号（竞品、替代、法规、失败案例）
3. 杀死条件分类：市场已饱和、技术不可行、法规禁止、已有开源实现
4. shortlist 门：至少 3 类杀死条件检查完成（不是必须找到，是必须检查过）
5. 对照：纯 brainstorm（无反证阶段）

## 验收指标
后续被现实否决的比例、shortlist 质量（用户评分）、从创意到立项的时间、反证阶段的 token 成本。

## 最大未知
反证搜索的覆盖面和质量，以及"杀死条件"的分类是否合理。
