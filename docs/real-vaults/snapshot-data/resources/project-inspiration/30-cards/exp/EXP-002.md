# AI 改代码的影子工作区 + build 门

## 用户场景
让 Coding Agent 自动改 Python / FastAPI 项目，但不能直接动工作区、不能"说改好了"就信。

## 最小功能
- 复用：shadow clone + 真实 build/test gate + rollback 丢弃。
- 新做：用 git worktree / 临时目录 clone → Agent 只在 shadow 改 → 自动跑 pytest / build → 通过才生成 patch / PR；失败丢弃并报告，主仓零改动。

## 对照组
Agent 直接在主分支改 vs shadow + gate。

## 验收指标
注入 N 个会破坏测试的改动，gate 100% 拦下；能通过的改动 100% 真实测试通过；失败时主仓零改动。

## 最大未知因素
测试覆盖不足时 gate 给出假信心。
