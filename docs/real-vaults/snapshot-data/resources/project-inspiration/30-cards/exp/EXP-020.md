# PRD 审计 Deterministic Feasibility Gate with veto

## 用户场景
PRD 审计工作流中，依赖缺失、测试环境不存在、资源预算超限时，Reviewer 不能被"尽力完成"语气覆盖，必须能产生 NO-GO。

## 最小功能
- 确定性检查清单（依赖/环境/预算/权限）→ 计算可行性分数。
- Reviewer Agent 有 veto 权：命中硬约束则输出 NO-GO，不可被乐观语气覆盖。
- 输出 GO/NEGOTIATE/NO-GO + 反方案（延期/加资源/缩减范围）。
- 复用 [[PTN-020]] [[PTN-022]]，Python 实现。

## 对照组
A：建议型 Reviewer（只提风险，无 veto）；B：拥有状态否决权 Reviewer。

## 验收指标
错误开工率（不可行项目被放行）、NO-GO 正确率、反方案采纳率。

## 最大未知因素
硬约束清单的完备性；veto 滥用（过度保守）的校准。
