## 实验目标
函数级 Zero Trust：Researcher 可以调用 resume.get_skill_summary 却不能拿到整份私密简历；购物 Agent 能调用 budget.can_spend(299) 但不能读取银行卡信息。

## 复用什么
- HORS 的 Function-level Zero Trust 机制（PTN-060）
- declarative policy（origin/assurance/executor）+ SIWE 签名绑定 function+hashArgs

## 新做什么
- 函数级能力目录 schema（principal_scope、arg_constraints、assurance、executor、side_effect_level）
- MCP server adapter 包装 registerTool 为 gated version
- handler 收到 ctx 包含 caller principal 而非原始签名

## 如何验证
对照：A. 共享 API keys（任何 Agent 能调用任何函数）；B. 函数级能力目录。指标：prompt injection 后越权调用成功率、数据泄露量、合法调用误拦率、性能开销。
