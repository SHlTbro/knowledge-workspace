# 动态角色 + bounded dissent reviewer（AI Coding）

## 用户场景
AI Coding 工作流不固定每个任务都拉满 Coder/Reviewer/Debugger；先根据 failure signature 动态选角色，再加一个只负责证明当前方案不成立的 bounded dissent reviewer。

## 最小功能
- failure signature 分类（语法/逻辑/性能/安全）→ 动态选 2-5 角色。
- bounded dissent reviewer：只允许提出"方案不成立"的证据，不允许提替代方案。
- dissent 有结构化 veto 条件。
- 复用 [[PTN-019]] [[PTN-020]]，Python 实现。

## 对照组
A：固定 5-Agent 团队；B：动态 2-5 Agent + dissent。

## 验收指标
token 消耗、延迟、缺陷逃逸率、d reviewer veto 正确率（事后验证）。

## 最大未知因素
failure signature 分类器的准确率；dissent reviewer 与正常 reviewer 的职责边界。
