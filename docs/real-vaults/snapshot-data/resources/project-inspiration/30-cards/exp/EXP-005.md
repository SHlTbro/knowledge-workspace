# FastAPI Agent 的概率/确定/人工三边界路由器

## 用户场景
企业 Agent 处理含计算、规则、模糊判断的任务，需明确哪些走 LLM、哪些走确定逻辑、哪些必须人批。

## 最小功能
- 复用：三边界思想。
- 新做：boundary router，声明式标注子任务类型；规则 / 计算走纯函数（可单测）；模糊走 LLM；高后果动作进入"待签字"队列，人批准才执行。

## 对照组
全 LLM 黑盒。

## 验收指标
测试集上子任务被正确路由；高后果动作 100% 停在人批；确定性部分有单测。

## 最大未知因素
边界划分是否正确、是否漏过高后果动作。
