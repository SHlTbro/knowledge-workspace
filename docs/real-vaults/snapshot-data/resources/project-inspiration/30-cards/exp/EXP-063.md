## 实验目标
Vault / Agent Memory 检索中不同来源证据不等权，同一个结论可以由不同来源累积，但弱来源不能淹没高质量 ground truth。

## 复用什么
- BirdCLEF+ 的 Source-weighted Learning 机制（PTN-067）
- 伪标签是有预算的弱证据，信号强度与可信度对齐

## 新做什么
- 证据来源等级定义（VERIFIED 源码/真实测试 > AUTHOR_CLAIM README > SECONDARY 博客 > CLUE 线索 > LLM_INFER 推断）
- source-weighted reranking 算法
- 多来源累积证据评分（弱来源不能淹没高质量）
- 错误晋升率检测

## 如何验证
对照：A. equal-weight 检索；B. source-weighted reranking。指标：错误晋升率（低质量证据排到高质量前面的比例）、top-k 准确率、用户满意度。
