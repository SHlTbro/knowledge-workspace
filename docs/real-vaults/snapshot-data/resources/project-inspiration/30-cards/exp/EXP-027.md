## Agent Silent Failure Monitor — 任务无异常但目标未完成

**复用：** Agent 执行日志、tool receipt 机制。
**新做：** 定义"用户目标应完成"的预期结果，检测 Agent 声称完成但无对应 tool receipt / 无副作用的静默失败。
**验证：** 对比仅监控 exception vs 加 outcome telemetry 后发现的静默失败数和误报率。
