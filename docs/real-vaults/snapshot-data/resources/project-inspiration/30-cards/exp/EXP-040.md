## 实验目标
给 AI Coding PRD 做 Feasibility Gate：先验证需求格式，再检查仓库是否有对应模块、测试入口、依赖、时间预算和权限。

## 最小实现
1. 第一层：PRD 格式合规检查（必填字段、描述清晰度）
2. 第二层：可行性检查
   - 仓库模块映射：PRD 需求 → 仓库中是否有对应模块/文件
   - 测试入口：是否有可运行的测试来验证需求
   - 依赖检查：需求是否需要新依赖，是否与现有依赖冲突
   - 时间预算：预估工作量 vs 可用时间
   - 权限：需求是否需要超出当前权限的操作
3. 输出：PASS / NEEDS_INFO / BLOCKED + 具体原因
4. 对照：普通 PRD Reviewer（只检查格式和逻辑）

## 验收指标
"纸面 PASS 但执行 BLOCKED"的提前发现率、误报率、PRD 返工率、从 PRD 到实现的时间。

## 最大未知
仓库模块映射的准确率，以及可行性检查是否会过度保守。
