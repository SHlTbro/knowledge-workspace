## 旗舰 48h：Executable Agent Reliability Profile — 把 MCP/Skill 权限说明编译成自动负向测试

**为什么选它：** 与用户现有 local MCP、YY 审计、Skill 系统高度贴合；比"Agent Firewall"更有差异化——不是运行时只拦一次请求，而是把系统声明的能力边界变成可持续证伪的测试资产。

**用户场景：** 一个 MCP/Skill 声称：只能读 project A；只能写 docs/**；不能读 Secret；不允许跨项目；删除和外部发送需要显式授权。这些现在通常只是文档。

**最小功能：**
1. profile.yaml：capabilities、forbidden_actions、resource_roots、side_effect_class、approval_required。
2. Profile Builder 从 README/config/manifest 生成 Asserted Profile。
3. Test Compiler 自动生成正向与负向 probe。
4. 在隔离 fixture project 中运行真实调用。
5. Profile Validator 输出：ASSERTED_ONLY / VALIDATED / FALSIFIED / NOT_TESTABLE。
6. 每个 FALSIFIED 附真实 tool request、observed result、证据 hash。

**验收指标：** 注入 30 个已知越权配置/实现缺陷；violation recall；false positive rate；新增一个 capability 后测试生成时间；文档声明与真实行为 mismatch 检出率；不可测试声明比例；单次完整 profile 验证成本。

**最大未知：** 自动生成测试容易只覆盖"容易表达的权限"，漏掉语义越权（如允许写 docs/** 但写入了不应出现的个人数据）。首版必须明确：Profile Validator 是权限/行为证据工具，不是万能安全证明。
