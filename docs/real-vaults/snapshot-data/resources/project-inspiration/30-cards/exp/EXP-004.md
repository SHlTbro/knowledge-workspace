# 会议纪要 → 带权威依据的 issue（MCP）

## 用户场景
把会议 / 需求文本转成结构化任务，且每条任务带权威文档依据，再写入 issue 系统，减少无依据返工。

## 最小功能
- 复用：非结构化 → 权威依据 → 结构化 schema → 写入；MCP 模式。
- 新做（Python + MCP/API）：抽取任务 → 检索官方文档（RAG over docs）→ 把依据链接附进 acceptance criteria → 通过 MCP / API 建 issue（GitHub Issues / Jira）。

## 对照组
无依据直接建 issue。

## 验收指标
建出的 issue 100% 带可点击依据；人工评估依据相关性达标；返工率下降。

## 最大未知因素
权威源覆盖度与检索相关性。
