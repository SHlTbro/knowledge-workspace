## 实验目标
在招聘 Agent 中做"推荐 abstention"：当 JD 事实完整度或候选人证据不足时禁止输出"强匹配"，只能升级人工确认。

## 最小实现
1. JD 完整度评分：必填字段覆盖率 + 描述具体度
2. 候选人证据评分：CV 中与 JD 要求对应的事实数量 + 可验证比例
3. abstention 门：任一评分低于阈值 → 禁止"强匹配" → 输出"证据不足，需人工确认"
4. 对照：无 abstention 门的普通匹配

## 验收指标
投递错误率（错误强匹配）、漏投率（该匹配但被 abstain）、用户修正量、人工确认后的通过率。

## 最大未知
阈值设定是否合理，以及 abstention 是否会导致过度保守而降低效率。
