## 实验目标
编排器只有在能力匹配且 reliability 达阈值时才自动调用 Skill/MCP，高风险工具即便分高也保留额外 gate。不只看 README 自我声明。

## 复用什么
- AgentRanker 的 Trust-before-Delegation 机制（PTN-054）
- reputation pattern 检测（self-review/集中账户互评）
- 可配置 trust threshold + approve/block 记录

## 新做什么
- 定义 Skill/MCP 的 Observed Reliability 指标：成功率、dangerous failure 次数、版本新鲜度、最近一次验证时间、用户/Reviewer 信号
- 编排器中插入 reliability gate，不达标则 block 或要求人工确认
- 高风险工具额外 gate（即便 reliability 高）

## 如何验证
对比：A. 传统"按 README 能力匹配调用"；B. Observed Reliability Registry。指标：调用失败率、dangerous failure 率、人工干预率、任务完成率、平均调用延迟。
