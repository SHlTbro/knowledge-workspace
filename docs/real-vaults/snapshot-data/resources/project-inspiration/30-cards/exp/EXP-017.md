# 内部供应商模拟器 + 并行外呼验证

## 用户场景
验证"并行电话询价 Agent"的结构化提取准确率和错误升级策略，但不碰真实外呼合规风险。

## 最小功能
- 建 10 个 mock vendor voice endpoint（不同报价/交期/模糊回答/口音）。
- Agent 并行外呼 → 结构化提取报价/交期 → 比较表。
- 模糊/矛盾回答触发错误升级（转人工或追问）。
- 复用 [[PTN-017]]，Python + Twilio 测试号或纯 mock。

## 对照组
A：串行逐个处理；B：并行外呼+结构化。

## 验收指标
结构化提取准确率（报价/交期/条款）、错误升级召回率、并行总时长 vs 串行。

## 最大未知因素
mock 与真实电话的差距（口音/背景噪/打断）；不直接验证真实合规。
