## 实验目标
Skill 的 registry metadata 不只存"我会什么"，还要存"最近一次在什么 benchmark、什么版本下做得怎样"。新版本发布后旧评分自动过期。

## 复用什么
- GoldenMCP 的 Verifiable Service Benchmark as Discovery Metadata 机制（PTN-056）
- security gate（触发直接归零）+ 三维评测（正确性/工具路径/token efficiency）
- TEE attestation 思路（可简化为签名验证）

## 新做什么
- 定义 Skill Reliability Card schema：能力声明、最近验证版本、golden tasks、tool-path correctness、成本、dangerous failure
- Skill 发布时自动运行 golden benchmark，生成 Reliability Card
- 新版本发布后旧评分自动过期，不一次评测终身荣誉

## 如何验证
对比：A. 传统 Skill registry（只有 README 描述）；B. Skill Reliability Card。指标：用户选择 Skill 的准确率、调用失败率、dangerous failure 率、用户对 Skill 质量的满意度。
