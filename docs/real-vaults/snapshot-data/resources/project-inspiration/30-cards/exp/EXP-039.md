## 实验目标
给简历定制 Agent 增加 claim ledger：每个输出 bullet 必须附 source_span，无源内容自动 BLOCK。

## 最小实现
1. 输入：CV 文本 + JD 要求
2. 生成：Agent 输出 bullet 列表，每个 bullet 附 source_span（CV 中的字符偏移）
3. 验证器：检查每个 source_span 是否真实存在于 CV 中，且内容是否支持 bullet
4. BLOCK：无源或 source_span 不支持的 bullet → 自动删除 + 记录
5. 对照：只用 system prompt 禁止编造

## 验收指标
unsupported claim rate（无源声明比例）、用户修正量、生成速度变化、BLOCK 后用户满意度。

## 最大未知
source_span 的粒度（句子级 vs 短语级），以及验证器本身的准确率。
