## 实验目标
Agent 故障分类不只用日志文本，加入调用图、时间序列、截图、trace topology 后是否有结构性提升。

## 复用什么
- Biohub 的 Representation Shift 机制（PTN-066）
- "系统是否根本没有看到决定性信息"的诊断思路

## 新做什么
- 多 representation 特征提取（日志文本 + 调用图 + 时间序列 + 截图 + trace topology）
- 单 representation vs 多 representation 对比实验
- 新信号贡献度分析（ablation study）

## 如何验证
对照：A. 仅日志文本；B. 日志+调用图；C. 全部 representation。指标：root cause 预测准确率、新 representation 边际贡献、推理延迟。先证明新 representation 提供新信号，再考虑更大模型。
