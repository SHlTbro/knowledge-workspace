## AI Coding Evidence Locator — 审计结论必须指向具体证据

**复用：** 现有代码审查 Agent、git 工具。
**新做：** 每条审计结论必须指向 commit/文件/symbol/测试/配置行；不允许"这个改动有风险"的无证据输出。
**验证：** 对比纯总结 Reviewer vs 证据定位 Reviewer 的人工复核时间和误判纠正率。
