## 实验目标
给 local MCP / Skill Registry 做 decoy fixture：正常 read/write API 中加入可识别但无伤害的 prompt-injection 与越权诱因。

## 最小实现
1. 包装现有 MCP server，在返回内容中播种 L1-L3 canary（参考 Litmus 的 _seed_payloads）
2. canary 端点：/x/canary?tok=...，记录命中
3. 越权诱饵：在正常响应中加入"尝试读取 /etc/passwd"的隐藏指令
4. 对照：纯离线安全测试（显式 benchmark）vs 真实工作流嵌入测试

## 验收指标
两种方式发现的违规类型差异、canary 命中率、误报率（正常 Agent 被误判）、对正常工作流的性能影响。

## 最大未知
嵌入式测试是否会干扰正常 Agent 行为，以及 canary 载荷的设计是否足够覆盖真实攻击面。
