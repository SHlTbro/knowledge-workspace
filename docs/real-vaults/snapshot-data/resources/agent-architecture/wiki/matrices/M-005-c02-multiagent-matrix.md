# 矩阵定位
**架构对比**（非选型决策矩阵）：对比 C02 多智能体框架七种范式：对话驱动团队编排（autogen）、闭环学习单助手+子代理（hermes-agent）、角色驱动 SOP 流水线（MetaGPT）、Chat Chain 阶段链式（ChatDev）、沙盒社会模拟（generative_agents）、角色扮演对话（camel）、角色驱动+流程编排（crewAI），解决面试高频问题"多智能体框架怎么选"。**选型决策需配合"框架原生 eval 工具"维度（CB-18，从"公开榜单分数"改造为"用什么 harness 能测"）与"上游活跃度"维度（CB-16）**——本矩阵 11 个架构维度为静态源码对比，eval 工具维度回答"框架是否提供可复现评估闭环"，活跃度维度提供上游维护风险信号，三者结合才能支撑生产选型。中立性声明：格内结论全部回溯到七张 F 卡的代码级溯源，厂商自证数字仅 [UNVERIFIED] 不入正文；七卡 star 数均来自 F 卡 frontmatter/GitHub API 实测；活跃度数据来自 GitHub API 实测（2026-09-10）；eval 工具数据标注 URL+curl 实测 HTTP 码+置信度，无原生 eval 工具如实标 [待补]。

# 一页口径（30 秒版结论，面试直接背）
多智能体框架选型按协作范式分四谱系：**对话驱动**（autogen 6 种 Agent+3 种团队模式，适合通用多 Agent 协作；camel 双 Agent 角色扮演，适合简单任务协作）、**流程驱动**（MetaGPT 16 角色 SOP 流水线，适合软件开发全流程；ChatDev Chat Chain 阶段链式，适合轻量可定制开发流程；crewAI 角色驱动+流程编排+Crew/Agent/Task/Process 抽象+Flow DAG 扩展，适合结构化多 Agent 协作和工作流编排，58k★ 社区验证）、**模拟驱动**（generative_agents 25 Agent 虚拟小镇+认知架构，适合社会行为模拟和研究）、**助手驱动**（hermes-agent 单 agent 闭环学习+子代理+多平台，适合持续学习的个人助手）。选型核心：需要多 Agent 自由对话选 autogen，需要 SOP 软件开发选 MetaGPT/ChatDev，需要结构化角色+任务+流程协作选 crewAI，需要社会模拟研究选 generative_agents，需要持续学习个人助手选 hermes-agent，简单双 Agent 对话选 camel。
**上游活跃度提示（CB-16，2026-09-10 GitHub API 实测）**：高活跃（日更级）= hermes-agent / crewAI / camel；中活跃（1.5 个月）= ChatDev；低活跃（5 个月，官方 Maintenance Mode，已迁 Microsoft Agent Framework）= autogen；停滞（8 个月，开源开发停止，无官方迁移宣告）= MetaGPT；学术停滞（2 年）= generative_agents。**新项目慎选 autogen（已 Maintenance Mode）/ MetaGPT（开源停滞），生产选型优先 hermes-agent / crewAI / camel（高活跃）**。
