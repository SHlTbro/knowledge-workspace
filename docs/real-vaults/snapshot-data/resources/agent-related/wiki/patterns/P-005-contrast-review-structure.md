# 问题
单工具实测容易变成平铺直叙的功能罗列，观众看 1 分钟就走。需要一种叙事结构让 7 分钟的测评拥有两波独立高潮。神烦老狗本期（S-003）提供了完整样本。

# 各方解法对比（单来源分点，全部出自 S-003）
1. **立对照锚点**：主体演示建立"强"的预期后（[00:00:14]-[00:01:25]），立刻让最强竞品做同一道题（"那我们就用 GPT-5.1 来给大家做一个对照参考" [00:01:30]），竞品翻车（手柄被嘲"新款的眼罩""路边一条" [00:01:40]-[00:01:45]）反衬主体。此段触发弹幕爆发 01:40（intensity 0.9）。EXTRACTED + EXTRACTED（解析数据）。
2. **预设质疑**："这个时候可能有人要质疑，说这个 SVG 是不是很简单" [00:01:26]——替观众发问再反驳，提前堵住评论区主要攻击线。EXTRACTED。
3. **中场反转**：[00:04:17]"我刚发现一个事……前面的测试都是在网页上测的"→ 推翻前半段前提，换手机 APP 重测（[00:04:31]"得到了一个非常惊人的结果"）→ 第二波演示连爆（"哇操"×6，[00:04:53]-[00:05:33]）。两大弹幕峰 05:50（0.8）/ 06:00（0.87）全部落于此段——反转是全片真正的高潮。EXTRACTED + EXTRACTED（解析数据）。
4. **结论回扣标题**："在手机 app 上才是真正的碾压，GPT-5.1 跟它打下手而已" [00:06:32]-[00:06:36]（ASR 噪声），回答标题设问完成闭环。EXTRACTED。

## trade-off
- 反转结构的爆点依赖**真实发现**：必须是拍摄过程中真实踩到的坑（网页端降智），编排痕迹重会穿帮（INFERRED，依据：该反转伴随"我操我刚发现"的真实反应口吻）。
- 对照锚点花费约 1/5 片长在竞品上（[00:01:26]-[00:01:47]），等于给对手曝光；换取的是反差说服力。

# 推荐用法
- 完整版（3 分钟以上）：`主体演示 → 预设质疑 → 竞品对照（第一波峰：吐槽玩梗）→ 中场反转（第二波峰：碾压）→ 回扣标题`。
- 抖音 60-180 秒版砍成单波结构：前 20% 刻意建立平庸/存疑预期，中段翻盘；对照锚点移到封面对比图或评论区置顶，不占正片时长。
- 判断规则：只要测评过程中真实踩到"设置/入口/版本"类坑，一律保留为反转素材，不要在开头说破。

# 反面教训
- 支线要有结论：[00:03:48]"是不是降质了"的怀疑被搁置 30 秒后才由反转回收——B 站长视频可容忍，抖音版支线超 10 秒未回收就是掉完播点（INFERRED，依据 purpose.md 完播率导向）。
- 不适用于非实测类内容（观点/资讯）：反转依赖"演示结果可被推翻"这一前提。
- 预设质疑不可滥用超过一次，否则像自问自答的水词（INFERRED）。
