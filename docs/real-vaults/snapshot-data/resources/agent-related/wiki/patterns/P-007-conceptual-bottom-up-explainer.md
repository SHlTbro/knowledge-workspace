# 问题
做"XX 到底是什么/彻底搞懂 XX"类的澄清视频（distillation 争议、开源套壳之争、任何被用滥的 AI 热词），最大的坑是创作者默认观众和自己有共同背景，直接抛术语定义，结果概念一层套一层，观众在 1 分钟内流失。闪客（S-004）提供了一个可复用的"把乱词讲清楚"的讲解流程样本。

# 各方解法对比（单来源分点，出自 S-004）
1. **底层直觉先行——把概念还原成一个观众已有生活经验的意象**。先把大模型还原成"一个函数 f(x)=wx+b……本质是个填数游戏"，结构=函数长什么样、参数=w 和 b 这些数字（[00:00:47]-[00:00:57]）——所有后续概念（开闭源=数字公不公开、蒸馏=数字怎么来）都挂在"数字"这一个锚点上，不再引入新比喻。EXTRACTED。
2. **用语义漂移对照表解释"为什么大家吵不明白"**。"蒸馏"原始义=2015 Hinton 知识蒸馏（教师模型教学生模型、学 softmax 后 logits，[00:02:45]），大模型语境泛化为"训练数据用了另一模型的输出就算"（[00:03:00]）；"开源"从"开放源代码"漂移为"开放权重"（[00:01:36]）。两词各讲一次"原义→泛化义"，并配画面花字对照表（"传统语境：开放源代码/蒸馏/知识蒸馏KD ↔ 大模型语境：开放权重/使用模型输出作为训练数据"，OCR [00:03:57]）。观众从此能识别争论双方其实在用不同定义。EXTRACTED + EXTRACTED（ocr_texts）。
3. **概念讲完立刻回到当下热点做"应用题"**。铺垫完成后才回放 Anthropic 帖子本身（[00:04:09]"现在我们回过头再来看一下"），观众带着刚建好的概念框架去审一篇官方声明。EXTRACTED。
4. **"互联网无新数据+厂商互用输出已常见"作为语境补充**：连"为什么现在模型厂商互用输出训练已是常见玩法"也给了原因——公开数据快被榨干（[00:03:38]-[00:03:49]）。EXTRACTED。

## trade-off
- 底层直觉类比牺牲精确性：f(x)=wx+b 无法涵盖注意力机制等细节，专业观众会挑刺（INFERRED，依据该视频定位是面向"看到争吵不知道谁对谁错"的普通观众 [00:00:23]-[00:00:26]）；换取的是零基础观众 30 秒建立全片唯一需要的脚手架。
- 语义漂移对照在画面里是信息密度最高的部分（两张表 10+ 字段），需要观众暂停看；B 站长视频可承受，抖音版需降成"一词一屏"（INFERRED，依据 purpose.md 平台规范 + 字幕表字段数）。
- "彻底搞懂 X"式承诺标题（[00:00:27]"这一期视频我就为你彻底揭开这些名词背后的逻辑"）抬高了预期，一旦概念讲解环节拖沓，弃看发生在中段而非开头。

# 推荐用法
- 澄清/概念科普片固定四段式：`底层直觉（1 个贯穿全片的意象）→ 语义漂移对照（原义 vs 泛化义）→ 回到争议热点做应用题 → 收束为可复用判断方法`。
- 选意象规则：必须能被后续所有术语共用（"数字"同时解释开闭源、蒸馏、数据来源），否则每讲一个新词就要建一个新比喻，观众认知负担不降反升。
- 判断规则：一个概念如果网上存在"定义战"，先查它是否发生过语义漂移；讲过漂移后，所有"谁对谁错"的争论都能被重新表述为"双方在用不同定义"。
- 讲语义漂移务必配一张可截屏的对照表花字（传统语境 ↔ 大模型语境），它是观众转发/收藏的理由（INFERRED，对照表出现在 4 个 OCR 花字时间点的 1 个）。

# 反面教训
- 禁止跳过"底层直觉"直接罗列定义——那正是本卡要解决的观众流失点。
- 类比意象不可在中途更换：若开头把模型比作"函数/数字"，后文又用"大脑/黑箱"，脚手架断裂（INFERRED，依据是闪客全片持续复用"数字"意象）。
- 概念科普最忌自己也定义不清就开讲（闪客明确承认"蒸馏这个词的语义就十分混乱了" [00:04:18]）；蒸馏前先确认你讲的是哪个语境的定义。
- 本流程服务"澄清/概念科普"类内容；实测/情绪型视频（对照 S-005 的反转结构）不适用——那类观众要的是结果冲击不是概念框架。
