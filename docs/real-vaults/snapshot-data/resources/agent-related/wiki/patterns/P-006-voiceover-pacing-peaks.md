# 问题
录屏类视频画面天然静态，切镜率远低于快剪对标（本期 5.27/min，契约示例的快节奏可达 18.4/min）。信息密度和留存靠什么撑？神烦老狗本期给出了"低切镜 + 高口播情绪"的完整样本，可测定其高能点分布机制。

# 各方解法对比（单来源，S-003 解析数据 + 转写稿）
1. **数据面**：cut_rate_per_min=5.27（41 镜头/455s，平均 11 秒一切）；danmaku_density_per_min=58.02（历史弹幕口径，仅参考，C-108）。EXTRACTED。
2. **高能点分布**：4 个爆发点（00:40 i=1.0 / 01:40 i=0.9 / 05:50 i=0.8 / 06:00 i=0.87，全部 intensity≥0.6）**无一对应剪辑变化**，全部对应口播事件：玩梗演示（摆头风扇 [00:00:39]）、竞品吐槽（"路边一条" [00:01:44]）、反转 shock（macOS 网页 OS [00:05:41]"What the f..."）。EXTRACTED + INFERRED（判定依据：逐条对照转写话题与关键帧画面，4/4 通过 ≥2/3 同题口径）。
3. **口播节奏三件套**：
   - 感叹词扫射：反转揭示段 40 秒内"哇操"×6（[00:04:53]-[00:05:33]），用重复情绪词代替剪辑冲击。EXTRACTED；
   - 吐槽类比：把翻车产物类比成日常物（"新款的眼罩" [00:01:40]），给观众可复述的梗；EXTRACTED；
   - 自问自答："哪个模型现在可以做到这种效果？" [00:00:49] 制造 mini 悬念后立刻自答。EXTRACTED。
4. **弹幕接梗机制**：最高爆发（00:40）的 top_texts"你就说摆没摆吧"是观众用博主的演示内容二次造梗——博主抛梗（摆头开关），弹幕接梗，形成互动高能。EXTRACTED（top_texts）+ INFERRED（机制归纳）。

## trade-off
- 低切镜省制作成本、保留"陪伴感"人设；代价是冷流量场景（抖音信息流）留不住没有耐心的陌生观众——神烦老狗的高能曲线建立在订阅粉丝信任之上（INFERRED，依据 purpose.md 平台规范：B 站时长结构不可搬抖音）。

# 推荐用法
- 抖音录屏视频必须**外挂剪辑节奏**（对标柱子哥式快切 + 数据动效，见 purpose.md 形态维度），本卡的口播情绪曲线叠加其上，而非替代。
- 高能点排布：B 站 7.6 分钟 ≈ 每 70-90 秒一个（本期 4 个）；抖音版压缩为每 15-30 秒一个情绪点（INFERRED，按比例换算 + 前 3 秒生死线约束）。
- 判断规则：每段演示先找"可玩梗的点"（意外行为/翻车/夸张细节），找不到梗的段落压缩时长；反转/翻盘段留给最大情绪词密度。

# 反面教训
- 弹幕密度/爆发强度受历史弹幕与复读影响（C-108、文本折叠口径），只能作参考，不可作硬论断——本卡以 top_texts 人工判定补强。
- "哇操"式情绪词在 B 站人设下是真实感，直接搬到抖音易被判定为夸张表演，需配合真人出镜（形态维度对标）消化（INFERRED）。
- 不适用于教学讲解类（需要平稳语速收信息）——本卡机制专服务"实测/开箱"情绪型内容。
