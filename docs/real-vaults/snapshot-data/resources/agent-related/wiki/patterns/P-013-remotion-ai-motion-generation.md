# 问题
AI 博主视频需要"画面动效"，但扩散模型（Stable Diffusion/Sora 类）只能生成"你想不出的画面"，无法像素级精确控制每个元素（[S-006 A 00:00:28-36]）。要像 AE/剪映那样精确控制动效、又不想学几个月 AE，怎么办？答案是用"代码搭画面的" Remotion + AI 当装配工。

# 各方解法对比
| 方案 | 做法 | 关键取舍 |
|---|---|---|
| 扩散模型 | 文生视频，出片快 | 无法精确控制细节/像素，成品带随机性 |
| AE/剪映 | 手动关键帧+图层 | 精控但学习成本数月、每期手工重复 |
| **Remotion+AI** | 代码搭画面，AI 读需求写 React，逐帧可控 | 精控+自动，但对 UI/图表/地图类最强，粒子/实拍非主场 |

# 推荐用法（给 agent 的直接行动步骤）
**选型铁律**：UI/软件演示、代码/终端、数据图表、2D 平面动效、地图 → Remotion 主场随便用；3D 场景 → 配 R3F/Three.js + 3D 模型文件；粒子/流体、实拍合成 → 别硬作，有更好工具（[S-006 A 00:06:41] 能/不能表）。

**工程脚手架（决定成品上限，最高优先级）**：
1. 项目根放 `CLAUDE.md` 写死审美偏好：分辨率 1920×1080 / 30fps / 动画风格 / 配色（"偏好 spring 动画，蓝色系"），新项目 AI 一上来就懂（[A 00:06:18-28]）。
2. 预装官方/自建 **skill 与模组**：告诉 AI "有哪些模组可用"——空项目 AI 只能从零生成（差），带 skill 显著提升（S-006 B 00:00:43-01:14）。

**提示词五式**：
- 方案先行："先跟我讨论你打算怎么做，不要做成 PPT"（减返工，[A 00:01:51]）。
- 让 AI 选武器："你觉得怎样才能极致酷炫"（AI 推荐库 [A 00:02:44]）。
- 图表述求：要"财经媒体那种丝滑的竞速图"，或直接扔参考图（图表成败在所选前端库 [A 00:03:05]）。
- 地图外挂：接真实底图（国内高德 / 海外 Mapbox 免费额度 + API key），"光靠模型脑补不行"（[A 00:03:33]）。
- 整段视频喂给 AI："装 ffmpeg skill 读每帧"还原效果，比嘴描述高效（[A 00:03:59]）。

**长视频四段式**：分镜设计→AI 搭时间线骨架（视频/音频/字幕三轨）→逐镜头做→整体调优；"动效是辅助讲解不是替代讲解"，通常做小片段嵌入（[A 00:05:51-06:17]）。

**进阶**：说不清的 3D 参数让 AI "暴露成可调属性"，在预览里改数字实时看（快十倍，[A 00:04:34]）；导出透明序列帧（ProRes4444XQ+PNG）配合剪映/达芬奇。

# 反面教训
- 空项目硬让 AI 生成 = "拿乐高积木拼高楼"，必崩；先给脚手架（skill/模组/CLAUDE.md）再干活。
- "光靠模型去脑补"做地图/数据=会出"同样的提示词你做出来就是这样"的翻车样（[A 00:03:30]）。
- 不要用嘴描述复杂轨迹/3D 角度，效率极低，要用图片轨迹线/参数属性化。
- 透明效果必须 ProRes4444XQ+PNG，否则透明失效（[B 00:04:16-29]）。
- 适用边界之外（粒子/实拍合成）别硬 Remotion，有更好工具。
