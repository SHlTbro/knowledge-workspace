# 问题
AI 工具实测类视频海量同质，标题和开头 3 秒决定点击与留存。神烦老狗（B站 13.9 万粉）是 purpose.md 指定的"文案/标题"维度对标，需要提炼其可复用的钩子公式，供抖音起步期直接套用。

# 各方解法对比（单来源分点，全部出自 S-003）
1. **标题双段式：断言 + 竞品设问**。"Gemini 3.0 彻底杀疯了！GPT-5.1 还有活路吗？"——前半句给出极端结论完成站队，后半句抛出对手存亡问题制造冲突。EXTRACTED（manifest.title）。抽象公式（INFERRED，依据为该标题结构拆解）：`[主体] + [冲击动词断言] ！+ [竞品] + [存亡/排名疑问]？`
2. **冷开场蹭时效**：第一句话就是昨天的事件（"昨天 GPT 发布了 5.1" [00:00:00]），无片头、无自我介绍、无"今天给大家带来"。时效事件 = 点开理由。EXTRACTED。
3. **免责式夸张**："我不想说很夸张的话，但这次真牛大了" [00:00:10]——先声明克制，再放极端判断；给夸张装上理性护栏，降低观众反感与"恰饭吹"怀疑。EXTRACTED。
4. **证据前置承诺**：3 秒内点明"可以直接用他们的最新模型" [00:00:03]，14 秒处第一个成品演示出现 [00:00:14]——标题的承诺在开头 15 秒内开始兑现。EXTRACTED。
5. **价值堆叠清单钩子（S-005 增补，抖音 11.6 分钟合集型）**：Bob同学开场无寒暄连抛五重承诺——"18 个工作流"（数量）+ 三领域（覆盖）+ "最新的开源模型"（时效）+ "免费分享"（价格）+ "本地部署"（自主权）[00:00:00]-[00:00:18]。抽象公式（INFERRED，依据为该开场结构拆解）：`[数量承诺] + [领域覆盖] + [最新开源] + [免费] + [低门槛]`。站队式抢点击，堆叠式抢收藏——收藏动机来自"资源以后用得上"。EXTRACTED（口播事实）+ INFERRED（公式与收藏动机归纳）。

## trade-off
- 站队式标题天然树敌（竞品粉丝），换取点击与评论区争论热度；若正文证据不足会反噬信誉（INFERRED，依据：该视频正文用整个 GPT-5.1 对照段支撑标题断言）。
- "杀疯了/牛大了"类程度词高频复用会通胀失效——神烦老狗以具体演示细节（灯光贴图/捕捉动画 [00:00:54]）兜住夸张。INFERRED。

# 推荐用法
- 抖音标题/口播第一句直接套双段式：`新模型/新工具 + 一句断言 + 一个对手或质疑疑问`。
- 前 3 秒必须完成三件事：**时效事件、立场表态、演示承诺**；15 秒内出现第一个可视化成品。
- 夸张判断前挂免责从句（"我不想说夸张的话/说实话"），极端词后立刻给具体细节佐证。
- 公式按内容类型选型（S-005 增补，INFERRED）：测评对比型 → 站队式；资源合集/教程型 → 价值堆叠式（数量+免费+低门槛），且开场承诺必须在片尾有资源交付回扣，否则收藏钩落空。

# 反面教训
- 标题站队要求正文真的交付对照证据，否则评论区反噬、掉信任。
- 抖音首发场景不得直接搬 B 站 7.6 分钟结构与钩子节奏（purpose.md 平台规范：B 站对标卡只用于选题/文案策略）；冷开场前 3 秒在抖音要压缩得更狠，"免责从句"超过 1.5 秒就会拖死前 3 秒完播（INFERRED，依据 purpose.md 前 3 秒生死线）。
- 不适用于无竞品、无时效事件的题材——公式依赖"对比锚 + 新鲜事"，硬套会空。
