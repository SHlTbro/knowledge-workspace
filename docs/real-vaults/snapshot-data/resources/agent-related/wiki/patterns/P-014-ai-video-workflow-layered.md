# 问题
AI 博主不出镜、要"全自动做好一期视频"，但只拿到一个 mp4 不够发——一期内容还差封面、多平台文案、博客、真人录音。官方出片 skill 只管"画面+渲染"，发布物料与真人录音得自己补。S-007 给出把"剩下一圈"也自动化、并让真人声音无缝接进流程的分层架构。

# 各方解法对比
| 方案 | 做法 | 关键取舍 |
|---|---|---|
| 官方出片 skill | hyperframes(HTML 即视频) + face-less-explainer(文章→视频) 全自动出片 | 只出 mp4，封面/文案/博客/录音仍手工 |
| 全手工 | 每期封面+文案+博客+录音全手工重走 | 实打实重复劳动 |
| **分层编排 skill** | 官方出片 + 自建薄编排层补齐物料与真人录音 | 一次交付整包物料，但依赖官方 skill |

# 推荐用法（给 agent 的直接行动步骤）
**分层架构三件套**：
1. **出片层 = 官方 skill**：hyperframes 核心入口（一帧一屏，agent 逐帧搭画面再渲染成片）+ face-less-explainer（一篇文章/主题→一段讲解视频）；取音频/图片/logo 交给 media skill。一行 `npx skills add <仓库>` 安装（[S-007 00:05:20-48]）。
2. **编排层 = 自建薄 skill**：不重做视频本体，只补齐官方不管的——交付清单 = 成片 + **5 比例封面**（16:9 给 YT/B站，9:16 给抖音/视频号，16:10/3:4/4:3）+ **两套平台文案**（YT/B站版式不同）+ 博客 + 社媒推文，差一样不算做完整期（[00:01:21-02:11, 00:03:36]）。
3. **旁白双源**：默认留"自己录"选项（TTS 克隆"像但平、没情绪起伏"→真人录制是刚性需求）；自己录时把音频+字幕交给 skill，**按句切分/对齐时长/把每帧内容重排到真正念到的时间点**，让画面自动跟着真人声音走（[00:02:17-03:12, 00:04:02-17]）。

**skill 写法（上下文工程新规则）**：SKILL.md 只写 60 行——只讲清"怎么用/开局问什么/交付什么"，细节下沉到 references 用到再读，硬规则只留几条，其余交给模型判断，"不为每件小事写规矩"（[00:04:48-05:10]）。开局先问两件事：用哪套设计（预制风格配色版式）/ 旁白自己录还是 TTS（[00:05:53-06:03]）。

**流程起点**：skill 是从真实制作经历"做到一半顺手整理出来"的——识别每期重复动作，抽成固定流程，而非专门设计（[00:04:26-48]）。

# 反面教训
- 不要重做出片本体——编排层越薄越好，官方 skill 负责难的画面渲染（[00:03:16-26]）。
- SKILL.md 别写成每条规则都列的"规矩大全"——薄主文件 + references 下沉，否则上下文被灌满、模型失去判断力。
- 真人录音必须做"按句对齐到口播时间点"这一步，否则画面与真人语速脱节，比 TTS 还违和。
- 封面 5 比例、两平台文案必须"一次生成到位"，否则退回手工、失去自动化的价值。
