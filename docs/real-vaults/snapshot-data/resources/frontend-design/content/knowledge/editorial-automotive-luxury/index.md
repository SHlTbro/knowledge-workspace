# 高端服务编辑式排版

任务：为高端汽车/服务类站点用编辑式排版建立专业感，避开"黑金 + 跑车大图"的俗套，靠版式和信息节奏而非堆装饰制造精密感。
检索词：automotive、luxury、editorial-grid、service-matrix、image-led、industrial-type、编辑风、高端服务、工业字体、细小编号。
摘要：用强硬短句（"RUN IT. HARD"）+ 大图建立力量感，同时用细小编号、斜杠、栏目缩写制造精密工程感；动效克制，重点在摄影滚动与细微 hover。本轮仅取得报告二手描述。
适用（INFERRED）：高端汽车/服务、工业奢侈品牌；需要靠版式节奏而非黑金配色建立专业感。
不适用（INFERRED）：需要强促销/密集转化的电商首页；未取得具体字号/断点证据，不在排版数值上做断言。

## 机制与理由

高端感的来源被从"配色"转移到"版式纪律"：力量感由大图和短句承担，精密感由细小编号、斜杠分隔、栏目缩写这类工程文档式符号承担。动效刻意克制——不是每个元素都动，只有摄影滚动、展车加载和细微 hover，专业感来自节奏而非炫技。

## 页面拆解

- 文案层：强硬短句宣言（如"RUN IT. HARD"）。
- 信息层：细小编号 + 斜杠 + 栏目缩写（工业/工程感）。
- 视觉层：大图/视频主导。
- 导航骨架：使命 → 愿景 → 服务矩阵 → Racing → Showroom → Media/Events → Contact。
- 动效：摄影/视频滚动、展车加载、栏目切换、细微 hover（克制）。
