# 第一人称体验式首页

任务：用极简界面承载第一人称主观体验，让 UI 元素退后，由运动视角、声音、节拍和叙事节点承担导航职责。
检索词：first-person、experimental-web、ai-storytelling、minimal-ui、immersive、motion-led、体验式首页、界面退后、主观视角。
摘要：进入即体验，不先解释；交互核心来自运动视角、滚动/输入反馈与叙事事件。UI 越少，运动/声音/节拍越要承担导航。本轮仅取得报告二手描述，技术栈未核实。
适用（INFERRED）：实验性品牌首页、沉浸式叙事、作品集式证明页；用户愿意投入数分钟经历一段主观旅程。
不适用（INFERRED）：信息密集、需快速找到功能的工具型站点；未取得具体技术栈，不在实现细节上做断言。
关键未知（UNVERIFIED）：具体技术栈未核实、运动/声音实现、节拍导航机制、性能、可访问性（键盘/读屏）、reduced-motion、许可证条款均未取证。

## 机制与理由

"UI 退后"不是没有界面，而是把导航职责从按钮转移到运动与声音：用户靠视角变化、滚动/输入反馈和叙事事件的节拍判断下一步。界面越极简，对运动连贯性和声音节奏的要求越高——这是一种尺度控制，而不是偷懒少画 UI。

## 页面拆解

- 进入：体验门槛（不先做信息解释）。
- 主体：第一人称骑行 / 运动视角。
- 节点：事件 / 叙事节点随推进出现。
- 结尾：作者信息 / 出口。
- 导航职责：由运动视角、滚动/输入反馈、声音、节拍承担，而非常规菜单。
